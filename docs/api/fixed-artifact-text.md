# Fixed artifact text and exact quotations

This protocol reads an already accepted ordinary UTF-8 artifact without buffering or copying its full source. It does not change workspace, draft, Run ingestion, provider limits, or the model JSON argument budget.

1. Call `artifact_text_prepare` with `{artifactId, sourceDigest}`. The first preparation streams and hashes the existing CAS source and builds a derived block index. It runs outside a synchronous SQLite writer transaction. A matching authenticated document index is reused. The result is `{artifactId, sourceDigest, size, textSourceId, readProtocol:"fixed-text-v1", utf16Length, status:"ready"}`.
2. Call `artifact_read` with `{artifactId, readProtocol:"fixed-text-v1", sourceDigest, textSourceId, cursor:0, limit:16000}`. `cursor`, `end` and `totalBytes` count original UTF-8 bytes; resume from `end`. Each page contains at most 16000 body bytes and complete characters. `utf16Start`/`utf16End` retain the original BOM-inclusive UTF-16 locator space. The returned `artifactReadId` identifies that one page.
3. Call `evidence_register` with `{artifactId, readProtocol:"fixed-text-v1", readId:artifactReadId, exactQuote}`. The quote must occur exactly once inside that page and cannot split a character. For a quote crossing pages, explicitly reread a bounded overlapping page. Agent registration requires that page's exact successful SDK delivery ACK for the same actor/session/task/attempt/generation and permission. Owner registration explicitly confirms its own manual read record; it does not create a fictitious SDK delivery fact.
4. Call `evidence_read` with `{evidenceId}`. Registration and subsequent evidence verification/readback perform bounded-memory full-source SHA-256 verification, then verify the quoted byte range and its original UTF-16 locator. The result retains the existing `locator` and `quote`, with `fixedText` describing the protocol, source/read IDs and byte range. Byte integrity does not verify scientific interpretation.

Preparation has an absolute 120-second service deadline; only this operation receives a 140-second worker RPC budget, including cleanup/delivery allowance. Existing-CAS indexing checks cancellation/deadline at 64 KiB I/O and index/hash iterations, with full current authorization at each 1 MiB source block and every publication boundary. In-progress machine bytes remain private staging data; revocation or expiry prevents a ready result. Upload validation and page/ACK/quotation authorization remain unchanged.

For `confirm` or `autoEdit`, the existing exact approval may resume a quotation in a later worker generation. Only the Registry's currently executing approved action can consume the already delivered original-generation page; the action must have been proposed in that page's generation and retain the same session, stable execution identity, full input, source and permission. The original receipt is never relabeled as a new-generation delivery. A completed action can only replay its stored evidence, not create another one. Direct later-generation reuse, pending/Owner pages, fabricated action IDs and changed bindings remain denied.

Every new read, replay and SDK ACK checks the original artifact's current authority. Derived IDs never authorize content. Existing project, task, wakeup, private-material, PDF and PMC restrictions remain. Discovery-revoked Owner history remains readable; new quotation registration and current scientific use still require current source validity. Owner history can be prepared/read in archived projects. Lowering the accepting file policy does not invalidate previously accepted originals.

Development reviewers retain their existing ordinary 2 MiB limit and the exact approved stdout/stderr log exception (at most 16 MiB). Generic byte receipts do not provide the legacy mandatory review-reading coverage. Calls without `readProtocol` retain the previous UTF-16 cursor and whole-source `exactQuote` uniqueness semantics.

Preparation publishes only the index: private entries/index staging, durable project/source publication intent, CAS link, then the ready descriptor. Interrupted publication retains ownership for backup/relocation/purge and never removes a shared CAS destination. Normal operation creates no unknown external-operation marker that would strand a crashed project. Backup validates mandatory source artifacts; offline purge can resume after some planned CAS files have already been removed and still rejects unexplained external hardlinks.

A concurrent publisher can remove its own redundant stage hardlink while another publisher verifies the same index. Only fixed-index publication may respond to `ARTIFACT_CHANGED` with one fresh open and complete SHA/size/identity proof, after rechecking the deadline and authority. It never rewrites or deletes CAS. Corrupt bytes or another identity change remain failures with durable ownership retained.

`artifact_create` retains its existing argument budget. Its actual post-redaction UTF-8 byte length is checked against the configured ordinary file policy and existing generation cap before CAS publication. Binary/provider budgets are unchanged.

The isolated SDK regression is `node --test tests/integration/fixed-artifact-pi-http.test.mjs`. It defaults to 3 MiB and accepts `PI_RESEARCH_FIXED_ARTIFACT_BYTES` and `PI_RESEARCH_FIXED_ARTIFACT_TIMEOUT_MS` for capacity runs. It uses the pinned SDK against a local provider fixture and an already stored source with a distinct ordinary artifact ID. The fixture rejects whole-source `readFileSync` and source staging during the new flow, checks exact SDK delivery and quotation readback, and reports wire bytes/host peak RSS. It is not an external-provider or scientific validation run.
