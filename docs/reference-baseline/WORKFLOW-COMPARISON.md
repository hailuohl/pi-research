# 科研工作流行为说明

本文记录本项目实验冻结、运行契约、分轮血缘、助手边界和证据处理的实现选择。历史验收只证明其记录的范围，不代表当前所有环境已通过。

## 流程比较与处理

| 关注点 | 工作流目标 | 本版处理 | 类型 |
|---|---|---|---|
| 实验冻结 | 问题已被回答即保护节点，差结果或非正常退出不自动撤销 | 有数值也失败时保护；不确定失败新增人工评议；原始NaN保留为无效数值产物而不伪造可比较数字 | 等价目标＋更保守人工边界 |
| 运行契约 | 同树命令与环境固定，变化进入代码/配置 | 保留固定契约；新增批准后的文本变更进入新子实验 | 等价能力，非Git实现 |
| 分轮血缘 | 同轮选项同父，下一轮建立在保留结果上 | 原Campaign保留；4次真实示例重新验证，不把它称为模型科研 | 已有能力复核 |
| 完成触发 | 唤醒仅是信号，要重新核对所有终态，不只看一条通知 | 保留持久化全量结果对账；修复Pi恢复后的宿主通知遗漏 | 已修复 |
| 助手边界 | 独立副本、自包含任务、明确授权，不自动合并 | 维持独立目录；补齐只读产物和人工批准交接；没有打开共享写目录 | 已修复连接，开发测试仍缺 |
| 回传默认 | 默认唤醒主会话，--no-wake取消回传 | API默认不额外发起付费模型总结，界面创建计划显式复选并审批 | 有意差异，非bug |
| 文献任务归属 | 文献检索与最终候选排序由主Agent掌握，不委派整个检索循环 | 默认助手说明改为整理资料，最终策略/排序交回主协调者；仍允许独立literature角色受控检索 | 有意可扩展差异，不宣称严格同构 |
| 辅助会话启动 | agent.rs事务创建会话与spawn，由常驻宿主执行/唤醒 | 本项目统一服务+持久化任务+AgentHost | 等价架构思想 |
| 证据 | 先实际读取日志；不能靠状态推测数值；截断不表示没有 | 产物完整性与报告数值共用原始校验；只读产物分页；完整可点击富引用界面仍不足 | 修复后仍有产品缺口 |
| 审查依赖和冲突 | 本轮上游资料没有给出与Pi Research完全相同的审查DAG合同 | 两阶段图、全部声明审查门槛、冲突保留、交付验证是本项目增强，不能声称直接复制了原版逻辑 | 自有增强 |
| 审批策略 | 上游指导明确计算授权/分支边界 | 保留协作、结果判定、变更整合和Run独立批准 | 有意安全策略 |

## 仍然存在的流程缺口

1. 受控开发测试未实现。已有代码交接不代表Pi能独立调试任意项目；必须先验证Docker/开发测试，再谈真实自动修复。
2. 文献只有Crossref元数据，不等价于上游多源检索、阅读全文和逐主张复现。
3. Git工作树/差异、论文LaTeX/发布、远程工作台没有全面补齐。内容快照交接不冒充Git整合。
4. 预算仍按Agent尝试数控制，模型全局Worker上限仍为2；不是费用硬上限或GPU资源调度。
5. 主助手自主策略、对照设计、误差解释和科研质量没有真实Pi评测；固定脚本形成两轮实验不能替代该评测。
6. 用户仍需显式配置任务交付合同。新版不从自然语言中臆测历史合同，也不把旧空结果追认为满足新标准。

结论：本次缩小的是“任务提交/验收/产物/审批/实际执行之间断开”的程序问题。没有把整个项目宣传为完整科研工作台替代品或生产科研平台。
