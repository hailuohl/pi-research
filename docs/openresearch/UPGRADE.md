# 升级、保留和对照

本次没有改写两个输入 ZIP，两个输出分别从自己的输入派生。不要用增强包覆盖唯一一份修复基线，也不要让两版并行使用同一个数据目录。

## 原有数据

停止旧控制服务、Agent 和所有数据写入进程，完整备份原数据目录。正式 Run 是否仍在运行需要实际核对；关闭网页不是停机。新版通过 `PI_DATA_DIR` 指向原绝对目录，不能随意移动包含绝对路径的已有项目数据。

连接器配置和操作记录是新增类型；本次没有用户数据库全量迁移/跨系统回退测试。回退应恢复先前完整备份，而不是假定旧程序理解新记录的权限语义。先在备份副本或新目录验证。不要把任意两个版本同时运行在同一个 SQLite/文件目录。

四个新来源初始关闭；旧 Crossref 初始开启。网络请求上限与本地文本索引开关分开。使用密钥时仅在 `.env`/宿主环境填入自己的值，重启控制服务；不要上传 `.env`、access.token 或数据库给他人。

## 并排运行（PowerShell，两个终端）

终端 A，位于修复派生版根目录：

```powershell
$env:PI_DATA_DIR="$env:USERPROFILE\pi-research-fixed-skills-data"
$env:PORT="4317"
node dist/apps/server/index.js
```

终端 B，位于增强派生版根目录：

```powershell
$env:PI_DATA_DIR="$env:USERPROFILE\pi-research-enhanced-skills-data"
$env:PORT="4318"
node dist/apps/server/index.js
```

分别打开对应终端显示的完整地址，不共享令牌。此处是跨平台启动说明，Windows/WSL 实机本次未验收。

## 比较什么

同一公开查询/时间范围/来源/限额分别执行，保存结果种类、返回来源、原文定位、错误与请求数。远程检索受实时服务变化影响，要同时保留获取时间；正式质量比较应使用固定获准文档。

两版新增技能和连接器本身是同一套代码，不能把这部分当作增强版独有收益。差异只来自原有本地文本检索/MMR能力。词项未匹配不表示文献没有答案；MMR不是默认策略，不能把它当科学质量评分。
