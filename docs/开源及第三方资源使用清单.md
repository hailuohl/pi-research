## 9. 许可合规要点

1. **随包声明**：`dist/web/LICENSE.react.txt`（React/ReactDOM MIT）是唯一随运行产物分发的第三方许可全文；[THIRD_PARTY_NOTICES](../THIRD_PARTY_NOTICES.md) 同步说明来源与边界。
2. **不随包分发的依赖**：npm 开发依赖、Pi SDK 及其传递依赖不进入 dist；安装后保留各包上游声明，完整清单以各线 `package-lock.json` 为准。
3. **源码适配**：K-Dense（主线）、PaperQA（两线）、OpenResearch（本地线）的许可/声明文件保留在 `third_party/*/`、`third-party/paperqa/`，逐文件来源以 blob/sha256 记录；适配范围明确窄于上游，不宣称上游背书或行为对等。
4. **镜像内组件**：pypdfium2（含 PDFium 构建许可）、Pillow、Python 科研栈、Debian 257 包的许可声明按 setup 脚本保留在镜像内（`/usr/share/doc/*/copyright` 等），哈希锁定可复现。
5. **科研成果中的第三方内容**：下载的文献保留其自身许可，获取记录不授予再分发权利；成果包导出保留文献原 PDF、引用页、解析与许可记录，**许可未知不会被改写为已获再分发许可**；来源失效后阻止新导出，历史字节保留。
6. **测试素材**：验收用 PDF/文稿素材为自绘字形与位图或标注为软件测试材料，不使用第三方论文页面冒充。
7. **排除项**：不包含密钥、`.env`、认证文件、运行数据库、原生会话 JSONL 与大份原始日志。
