## Necessary repair ruling after actual 512 MiB verification

The first capacity flow fixed the source and completed the actual Docker host fixture, then failed with reviewer LEASE_EXPIRED. The first candidate page took 27.256 seconds and its offer another 3.068 seconds. A single 3 MiB direct-app probe measured six whole-dataset SHA passes per assertTaskCurrent: candidate execution 36, offer/ACK six each, existing-index data page 156, and generic prepare miss 601. These synchronous chains block the same Host heartbeat; transaction counters are db.isTransaction observations, not a separate lock-mode measurement.

For the new reading protocol, separate complete current authority/immutable descriptor checks from fresh whole-content integrity boundaries. Heartbeat, active-task/model guards, page authorization, offer/ACK and index checkpoints keep all current permission/role/source/task/attempt/generation/approval/provenance checks but do not repeatedly scan unrelated datasets. Preserve default full validation for legacy callers/protocols. Prepare, dispatch before worker start, any inspect that reports referenceVerified, original quote-verification semantics, acceptance and adoption/assertPassed retain fresh complete SHA/size/archive/method checks. Deduplicate each unique original within that boundary using private operation-local context only; never use a caller flag, cross-RPC persisted verified result or stat-only integrity substitute.

Long verification/index work must stay bounded and allow normal scheduling outside long writer sections, with cancellation/deadline and current authority fences and a final after-await recheck. Do not raise leases/RPC limits or revive expired execution. Reuse a preexisting workspace index only after exact project/artifact/digest/size, index provenance/identity and fresh source/index integrity validation, returning the original stable source ID without rewriting old bindings or receipts. New indexing and legacy/document fallback retain their ownership/integrity guarantees.

Lexically normalize path-like argv operands for comparison (`./`, `dir/../`, separators and the existing case policy) to close the independent role-conflict alias probe. Keep approved argv bytes and strict source/candidate path validation unchanged; no arbitrary shell-language interpretation is added.
