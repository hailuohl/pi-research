# Batch 2B: authorized artifact text to verified quotation

Approved overall scope: configurable ordinary originals default to 512 MiB, preserve permissions/evidence/history, and deliver independently validated batches. Batches 1 and 2A are already delivered; do not repeat them. This batch implements one flow: authorized ordinary artifact -> explicit index preparation -> bounded page -> exact SDK delivery -> one-page quotation registration -> verified readback/reopen.

## Public interfaces

- Add `artifact_text_prepare` with `{artifactId, sourceDigest}`. Return `{artifactId, sourceDigest, size, textSourceId, readProtocol:'fixed-text-v1', utf16Length, status:'ready'}`. Preparation is explicitly O(N) when needed, outside SQLite's synchronous writer transaction. It creates derived local read state, not model-reading coverage, scientific evidence or execution authority.
- Extend `artifact_read` with an explicit new branch `{artifactId, readProtocol:'fixed-text-v1', sourceDigest, textSourceId, cursor?, limit?}`. New ranges use UTF-8 bytes and at most 16000 body bytes; return actual start/end/total, original digest, UTF-16 correspondence and opaque `artifactReadId`. Legacy calls retain their old UTF-16/BOM/cursor meaning. Do not reinterpret old numeric cursors or truncate serialized result JSON.
- Extend `evidence_register` with a distinct branch `{artifactId, readProtocol:'fixed-text-v1', readId, exactQuote}`. Quote must match uniquely inside that one returned page, on complete-character boundaries. Derive the existing UTF-16 locator from authenticated byte/UTF-16 mapping; do not change legacy no-readId whole-source uniqueness semantics. Cross-page quotes must be reread as a bounded overlapping page in this first version.
- Agent registration requires a matching successful SDK-delivered page and current original artifact authority. Owner/manual calls retain owner authority: an owner may explicitly confirm its own owner-read record while registering, without manufacturing an SDK-delivered fact or allowing an agent to borrow that owner receipt. This distinction must be represented and tested, not a caller-supplied authorization flag.
- New evidence registration, verification and readback retain bounded-memory full-source SHA-256 checks. Do not silently replace old whole-source integrity with quoted-block-only verification. Old evidence fields/locators and cached historical results remain interpretable.

Internal helper and record names may follow the repository conventions; public field/name deviations require a root ruling before callers/tests diverge.

## Five acceptance conditions

1. A valid saved ordinary Chinese text beyond 2 MiB can be prepared, paged, quoted and read back; create validation uses actual stored UTF-8 bytes before CAS publication. Keep the existing model/JSON argument budget separate instead of accepting a 512 MiB JSON argument.
2. Preparation streams the existing fixed source without copying/staging its complete bytes. Reuse the authenticated block-tree format and existing document index when original project/artifact/digest/size match. Pages/byte-to-UTF16 mapping have bounded I/O/memory and preserve BOM, CRLF, Chinese, emoji and cross-block characters.
3. New agent quote receipts reuse the exact SDK ACK mechanism, including actor/session/task/attempt/generation and permission bindings. Pending/error/transformed/cached/late results cannot certify a quote; one-page uniqueness is explicit. Old exactQuote global uniqueness and source truth are unchanged.
4. Existing project/task/wakeup/discovery/PMC/PDF/private-material authorization runs before descriptor/index access and replay. The ordinary file policy cannot override exact reviewer stdout/stderr/job bindings or approved logBytes (at most 16 MiB). New generic receipts do not replace mandatory review-reader coverage; review migration remains later.
5. A derived index has durable project/source ownership before permanent CAS publication. Cancellation, conflict, crash/link windows, corruption, restart, backup/relocation/purge and shared CAS are safe. Never delete another publisher's hash or relax external-hardlink protections. No source or evidence is marked ready before completion.

## Implementation decisions

- Extract a descriptor-only authorization path from EvidenceService, keeping the complete existing checks and existing whole-buffer API for unmigrated callers. A descriptor alone does not grant body access. Native-continuation/control materials are not ordinary scientific quotation sources.
- Add a shared index builder over an already-fixed CAS source. Do not use the upload function that stages/copies the source. Reuse document index after original authorization; source-digest equality alone is not authority.
- Add a narrowly defined single-index publication intent and strict maintenance support, reusing current publication recovery practices. Existing CAS source already has an artifact owner; only the new index needs publication. Private staging stays inside the known project tree.
- Handle Registry asynchronous preparation/cache replay deliberately. A boolean alone is insufficient: current source authorization and prepared descriptor must be validated on replay and final publication, with short writer transactions.
- Extend the existing 2A host/worker result ACK instead of introducing a second transport. Artifact-specific verification must preserve task and wakeup identity. New byte results must not be passed to legacy review-reading code as UTF-16 coverage.
- Quote verification uses the fixed source and original existing UTF-16 locator. A character split at a 1 MiB checkpoint needs authenticated adjacent bytes; never decode from a UTF-8 continuation byte as an independent prefix.
- A trusted byte-budget parameter/helper may be needed so post-redaction generated bytes are checked before CAS writes. Preserve existing origin/redaction behavior and do not widen general binary/provider budgets or leave unowned rejected output.

## Necessary repair rulings after first integrated verification

- The actual 512 MiB SDK run exposed the generic 30-second RPC cutoff. Direct timing found 56.54 seconds preparation, with 25,609 full validations and 25,613 authorizations accounting for 91.6% of time. Only this preparation operation gets a shared 120-second absolute service deadline plus 20-second IPC cleanup/delivery margin; other tools keep their budgets. Fixed-CAS preparation checks cheap deadline/cancellation every 64 KiB, complete authority at each 1 MiB logical block and every publication/return boundary. Upload checks, page/ACK/quote checks and final current authority remain unchanged. The fixture must surface the actual tool error before parsing success JSON.
- Default confirm/autoEdit approval resumes in a new generation. Exact SDK offer/delivery checks remain strict. A host-only capability for the exact validated/begun `evidence_register` action may consume the original already-delivered page without rewriting its identity or claiming new-generation delivery. Bind complete input, project/session/operation, original action generation to original reader generation, stable actor/task/attempt/continuation identity, current approval/policy/source/permission, page bytes and full-source SHA. No caller-controlled trust flag or blanket generation relaxation.
- Completed exact-action replay is a separate validation-only capability: return only that action's already-stored exact evidence under current authority/integrity checks. It cannot begin again, create another evidence row or turn a completed action into an execution grant. New ordinary registrations remain subject to current-reader checks; a later generation cannot borrow an old page to mint a fresh approval that masquerades as original-generation recovery.

## Scope and validation

Expected files: evidence descriptor/index/read/quote service and domain/schema contracts, shared streamed storage/index publication and necessary maintenance, Registry/catalog/role/policy integration, existing host ACK adapter, and focused tests/docs. No dependency, layout, benchmark rerun, main-checkout mutation or main-service restart. One implementation agent; independent Astra/xhigh review of the integrated snapshot.

Write failing tests first for the Chinese size mismatch, old versus new duplicate-quote semantics, cross-block Unicode offsets, wrong/missing ACK, source permission revocation, task log scope, asynchronous replay, cancelled/crashed index preparation and reopen. A pinned SDK with local provider must exercise prepare -> read -> ACK -> register -> readback. Parent capacity verification includes 512 MiB while keeping model payload and host memory bounded. Reuse still-applicable batch1/2A evidence; finish with one full regression, clean build, independent review, explicit staging, commit/push and remote inclusion check.
