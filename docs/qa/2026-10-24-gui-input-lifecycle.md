# GUI 输入与项目生命周期修复（2026-10-24）

## 范围与验收

本批修复提供商 ID 的非法 HTML pattern，以及项目归档/回收站切换中的无效后台读取与误告警。空队列、抽屉标题、导航和前端布局维持既有设计；后端权限及生命周期拒绝边界不变。

1. 提供商 ID 首字符为 ASCII 字母/数字，其余允许字母、数字、点、下划线、连字符，长度 1–100；Chrome 原生校验无正则错误。
2. 归档历史不请求附件能力、不误报上传失败；取消归档后恢复读取。PNG/PDF 草稿保留，能力未知时仍限制发送，确认不支持时仍报错。
3. 项目管理打开前暂停并取消子组件读取；切换/卸载抑制旧结果，挂起请求不叠加，关闭管理后恢复。
4. 归档权限/审批历史仍可初次读取；已归档视图停止轮询。来源保存与读取取消使用独立身份，成功/失败均收尾，旧项目保存回复不污染新项目。
5. 取消归档、回收站及还原保留会话/已有产物，后端 409/410 约束保留。
