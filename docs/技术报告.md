报告日期：2026-10-29。主基线：远端最新工作线 `implementation/pr01-reproducible-baseline`，提交 `5f365a9`（2026-10-28），包版本 `0.3.1-experimental`。本地 `main`（`1ca34c27`，Pi SDK 1.2.0 升级线）的差异在第 10 节单列。

## 1. 项目概述

研舟π（包名 `pi-research`）是一个**本地优先、过程可追溯的多智能体科研工作台**，以 Pi 作为唯一 Agent 执行内核。核心思路：模型的每一步有副作用动作（源码、测试、运行、文献获取、文稿编译、成果导出）都经过统一契约验证、用户显式批准，并以不可变的固定版本（修订、快照、意图清单）留证，事后可按稳定 ID 回查。

- 定位：单机本地系统，服务仅绑定本机回环；不是托管服务。
- 项目自身 MIT 许可（LICENSE）。
- 由 `0.3.0-experimental` 独立派生，保留 0.2.x 的实验、审批、快照、协作、Campaign 与有效性修复。
- 当前阶段：本地后端阶段完成后按批推进；前端布局完整重构、桌面分发与团队产品协作暂缓（见 [PROJECT-GOAL](PROJECT-GOAL.zh-CN.md)）。

## 2. 运行环境与启动

| 项 | 值 |
|---|---|
| 核心运行时 | Node.js ≥ 22.19.0；开发固定 24.19.0（`.nvmrc`）、npm 11.17.0 |
| 默认端口 | 4317（`PORT` 可改） |
| 数据目录 | `<项目>/.pi-research`（`PI_DATA_DIR` 可指向独立目录） |
| 模型配置 | `PI_PROVIDER` / `PI_MODEL` / `PI_API_KEY`，本地 `.env`，不入库 |
| 预构建产物 | 仓库含 `dist/`，核心与工作台可直接运行，无需先装 npm 依赖 |

```bash
node dist/apps/cli/index.js doctor          # 启动自检：工具、数据、固定后端
node dist/apps/server/index.js              # 控制服务 + 工作台（本机回环）
npm run setup:pi                            # 按根目录锁定文件安装固定 Pi SDK 0.87.1
```

没有 Pi SDK 时系统不会伪造模型回答；真实模型调用需自行配置供应商凭据。

## 3. 系统架构

### 3.1 应用层（apps/，9 个）

| 应用 | 职责 |
|---|---|
| `server` | 控制服务：HTTP API、工作台静态资源、SSE 事件唤醒、调度入口 |
| `cli` | 命令行：`doctor`、`operation`、`skills`、`demo-campaign`、`backup` 等 |
| `web` | 工作台前端（React 19.3.0，本地打包，无 CDN 依赖） |
| `agent-worker` | 本地 Pi 主会话/助手 Worker，承载真实模型任务 |
| `execution-worker` | 计算执行 Worker（本地受信示例、Docker、SSH） |
| `literature-worker` | 文献检索/获取任务 |
| `document-worker` | 文档解析作业（隔离 Docker 内跑固定 PDF 解析镜像） |
| `publication-worker` | 文稿编译作业（隔离 Docker 内跑固定 TeX 镜像） |
| `runner-supervisor` | 受监督的正式 Run 进程（超时、输出与退出码捕获） |

### 3.2 领域包（packages/，21 个）

围绕统一领域模型分层：`domain`（核心实体）、`contracts`（操作契约与校验）、`storage`（持久化与 CAS）、`runtime`/`scheduler`（进程与调度）、`pi-adapter`（Pi SDK 适配）、`execution`/`runners`（计算后端）、`literature`/`connectors`（五源文献）、`documents`/`text-evidence`（文档版本、证据定位与本地检索）、`development`（私有实现/测试/审查流程）、`publications`（文稿/报告/成果包）、`collaboration`（团队/任务/授权）、`skills`（技能目录与版本）、`policy`、`evidence`、`research-tools`、`research-workflows`、`workspace`（项目工作区与 GitHub 源码同步）。

### 3.3 统一操作契约（OperationRegistry）

全部业务入口收敛到一个操作注册表：当前主线实测 **175 个操作**（实例化主线 dist 注册表核实；README 的 134、后端清单的 144 为较早时点数字）。每个操作声明：

- 精确输入/输出 Schema（TypeBox）；
- 权限（仅用户 / 限定 Agent 角色与项目）；
- 幂等策略（只读 / 幂等键 / 版本与摘要乐观并发 `expectedVersion`、`expectedDigest`）；
- 前置条件（来源有效、版本未冻结等）。

四类入口（工作台 HTTP、CLI `operation`、Pi 工具、内部调用）共用同一注册表；HTTP 的 `sessionId` 只选择工作区，不授予 Agent 身份。契约按域拆分为多组 schema 文件（含工作授权、Run 授权、发现授权、自动审批、方法契约、研究计划/简报/行动、正式报告审查、会话、调度等族）。

### 3.4 Pi 适配层与多智能体

- 固定 Pi SDK 0.87.1（`@earendil-works/pi-ai`、`pi-coding-agent`，含 chord 等子包 override；本地升级线为 1.2.0，见第 10 节）。适配层覆盖 ModelRuntime、SessionManager、createAgentSession、resourceLoader 等 SDK 接口，离线真实 SDK 契约测试纳入 `npm test`。
- 受管技能目录与按需读取工具接入 Worker；会话固定技能 bundle，读取资源不执行代码。
- 多智能体协作：研究对话输入框旁切换；开启后主 Pi 生成**有界分工**，用户批准后执行，结果回原会话综合；主线新项目默认开启多智能体，可手动关闭。
- 助手可按模型真实存在的自定义思考档位及用途策略选档，策略经模型管理接口保存、跨目录导入，批准后冻结执行映射（见主线 `docs/THINKING-ALLOCATION.zh-CN.md`）。
- 解除单次运行 12 轮 / 40 次工具调用 / 5 分钟固定上限；任务持续至完成或手动停止，工具超时、权限校验与故障处理仍生效。

### 3.5 执行后端与隔离沙箱

执行后端收敛为**本地受信示例、Docker、SSH** 三类；GPU 契约在主线已接线（local/Docker/SSH 的 NVIDIA UUID 分配与 DeviceRequests 已实现，真机验证仍为目标环境待验项）：

- 正式 Run：批准冻结清单后在 Docker 沙箱执行（非 root、只读根、资源限额）；`runner-supervisor` 统一捕获退出码与输出；SSH 目标走受信 Linux Docker 监督。
- PDF 解析（profile `pdfium-text-form-images-v3`）：pypdfium2 + Pillow 固定 wheel 哈希、镜像 digest 固定、构建断网；有严格页数/对象数/时长限额，不做 OCR，不声明阅读顺序或科学正确性。
- 文稿编译（profile `latex-document-v1`）：Debian trixie 快照锁定的 257 个包（TeX Live 三引擎 pdflatex/xelatex/lualatex、BibTeX/Biber、Poppler、Latin Modern 与 Noto CJK 字体），`--network none` 安装与运行；引擎禁 shell 转义与 Lua socket/ffi，并有针对性伪造探针。
- 科研回归镜像（可选，`examples/regression-libraries`）：numpy/scipy/pandas/scikit-learn/statsmodels 按版本锁定构建 `pi-regression-methods` 镜像，运行环境 digest 随 Run 记录。

### 3.6 前端工作台

React/ReactDOM 19.3.0 由 esbuild 打包进 `dist/web/assets/main.js`，运行时无 CDN 与外部字体依赖。会话为主入口；实验支持节点树图与列表；日志按 64 KiB 有界窗口回查（字节游标，正确处理中文/emoji 跨页）；断线用带鉴权 SSE 唤醒 + 按项目事件补拉 + 20 秒权威状态兜底，不重放旧回答。输入框支持消息排队/编辑/删除、文献来源勾选（站点图标，五源默认开启）、附件（每条消息最多 5 份 PDF/TXT/MD、每份 32 MiB）与会话级模型选择。

### 3.7 数据与持久化

本地数据目录内含业务数据库、内容寻址（CAS）来源对象、原生 Pi 会话历史、项目 Git 历史与技能发行归档。关键不变量：实验修订与快照不可变；Run 以批准时冻结的清单执行；文档导入形成不可变 DocumentVersion；技能旧版本按原字节归档。CLI `backup create/verify/restore --offline` 支持全量离线备份、校验与异址恢复重开。

## 5. 安全与权限模型

1. **本地边界**：服务仅监听本机回环，`local-owner-only`；Host 白名单；工作台直开本机地址，无需访问令牌；HTTP 入口不再按 Origin 或 Sec-Fetch-Site 拒绝请求（边界由回环绑定与身份模型承担）。
2. **身份不可伪造**：Agent 的 Actor、任务、租约和允许工具由控制服务建立；客户端不能自称 `user`；owner HTTP 请求不授予 Agent 权限。
3. **用户是唯一批准人**：所有有副作用的阶段（测试、整合、正式 Run、编译、审查、导出、Grant）都需要用户显式批准；模型判断不替代授权。
4. **有界授权**：WorkingGrant / RunGrant / DiscoveryGrant 把"批准一次"限定为精确的文件集合、冻结清单、来源范围、期限与提交计次；到期只关未来使用，撤销阻断依赖交付，历史记录保留。
5. **固定与可回查**：源码修订、实验快照、Run 清单、文档版本、技能版本、文稿修订均不可变；结果按固定 ID、页码、字符区间回查，原始响应与派生摘要分离存放。
6. **沙箱隔离**：解析与编译镜像非 root、只读根、无 capability、无网络；引擎禁 shell 转义/Lua socket；不挂载宿主凭据或 Docker socket；编译产物必须同时满足退出码、封闭 schema、无错误且收敛、字节/摘要校验才算成功。
7. **凭据管理**：供应商密钥只存本机（`.env` 或环境页私密配置），不进提示词、不提交仓库、不自动转发给 Docker/SSH 目标；文献密钥仅控制服务使用。

## 7. 验证与质量保障

```bash
npm ci && npm run typecheck && npm test && npm run test:parity && npm run verify:build
PI_LIVE_TEST=1 PI_PROVIDER=.. PI_MODEL=.. PI_API_KEY=.. npm run test:live   # 显式选择加入
```

- 测试规模：unit + integration + parity 共 **360 个测试文件**（主线实测计数）；`test:live` 默认跳过，需进程环境显式开启并使用自己的供应商额度，不读取全局 Pi 凭据。
- 验收记录按日期批次重组于 `docs/acceptance/`（如 `build-skills-repair-20261028`、`current-metadata-cleanup-20261027`、`independent-figures-20261027`、`researchclawbench-20261025`、大文件分批系列等），每批含结果与机器证据。
- 干净构建与打包校验：`verify:build`；另有双版本冻结源码回归（`test:baseline`）、旧数据升级验证（`test:upgrade`）、开发义务核查（`verify-development-obligations`）与大文件容量核查（`verify-large-file-capacity`）。
- 科研方法自动触发经过多轮真实 Pi 实测（第 4 节），失败证据保留，不以通过轮次宣称稳定达标。

## 8. 当前能力边界

沿用 [BACKEND-READINESS](BACKEND-READINESS.zh-CN.md) 的分类（该清单为准确入口）：

- **可用**：对话驱动的研究/实现/审查/实验闭环、五源文献与文档证据链、报告与成果包、技能生命周期、离线备份迁移、有界授权、历史分页回查、科研方法参考与回归库示例。
- **受限**：PDF 阅读顺序/表图结构/扫描 OCR；PMC 复杂表格语义；部分历史总览未分页；SDK 用量观察不等于真实账单；bioRxiv/OpenAlex 原 PDF 仍受限或待验。
- **需求触发**：更多 Task 授权、RunGrant 参数语言、新技能/模板、压力/恢复矩阵、成果对外发布、Overleaf；GPU 真机验证按目标环境进行。
- **暂缓**：前端布局完整重构、桌面分发/更新/回滚、团队产品协作（PR14）。

明确不宣称：编译通过不等于排版或科学审查通过；数据与成功条件是待验证声明；`accept` 审查结论不证明科学正确；许可未知不改写为已获再分发许可。
