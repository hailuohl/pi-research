## 实际变更

- `artifact_text_prepare` 显式为已获准的固定 CAS 文本建立索引，首次准备为 O(N)，只暂存索引；已有文档索引在原件归属和摘要匹配后复用。支持有效 UTF-8 文本，不增加 MIME 白名单。
- `artifact_read` 的新 `fixed-text-v1` 分支使用 UTF-8 字节游标，每页最多 16000 bytes，返回 UTF-16 对照位置。旧游标、BOM 和引文定位语义保留。
- 新引文绑定实际 SDK 送达的准确单页；Owner 可确认自己的手动读取记录。引文需在页内唯一，跨页须重新读取重叠页。登记、验证和回读保持流式整源 SHA-256 校验。
- 默认确认审批允许准确原操作在新代恢复；宿主凭据绑定原审批代、完整输入、原送达页、当前权限和来源。已完成操作只回放同一证据，不创建新证据，也不改写原回执。
- 索引发布前保存项目和来源绑定的持久归属，接入备份、恢复及清理。并发发布仅对固定索引允许一次重新打开、完整 SHA 和稳定身份复证；污染和再次变化仍拒绝。
- 生成产物按脱敏后的实际 UTF-8 bytes 检查配置上限，再写 CAS。保留模型参数、JSON、原生材料及审查日志的独立预算；普通配置不扩大审查授权。

接口和首版限制见 `docs/api/fixed-artifact-text.md`；五项验收见本批 spec。
