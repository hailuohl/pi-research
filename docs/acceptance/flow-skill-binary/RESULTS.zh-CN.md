# PR11：固定技能包中的静态 PNG 资源

本批开工前固定四项验收条件：

1. 用户从原生文件选择器导入仅含文本 `SKILL.md` 和 `assets/figure.png` 的受限 ZIP；系统保存原字节和摘要，审阅、批准、显式启用后，新会话固定该 bundle。导入与启用不运行模型或脚本。
2. 非规范路径、非文本入口、伪 PNG、超过原限制的文件及跨项目/Agent 访问均在发布或读取前拒绝，失败不形成可用修订。
3. 用户能从固定修订下载 PNG 原字节；`research_skill_read` 仍只返回文本，不能把二进制转为模型指令或执行权限。未知许可证保持未知。
4. 刷新和重开后原修订、摘要、审批、会话绑定及资源仍可回查；撤销阻止新启动，历史原件可读，既有纯文本技能记录保持兼容。

本批只接通这条静态资源流程。前端布局、通用图片渲染、脚本执行和原计划其余范围不扩入本批。

实际结果：`assets/figure.png`（2,021 字节，SHA-256 `9248c17b…b11918`）与文本 `SKILL.md` 成为同一不可变修订，PNG 类型和原字节摘要可审阅。损坏 PNG 的 ZIP 经 HTTP 返回 `SKILL_IMAGE_INVALID`，修订数仍为零；有效 ZIP 进入待审，页面批准、显式启用，新会话固定 bundle 并通过预检。用户按固定摘要触发 PNG 下载；重开服务后修订、会话和原件仍在。隔离验收中撤销后，新启动预检被阻止，历史 PNG 继续可读。没有调用 Pi 或 Docker，未知许可证没有被升格。

PNG 只在 `assets/` 下按原字节保存/下载，不进入模型文本，也不授予脚本执行。导入与再次读取核对容器结构、CRC、有界解压、扫描行和动画块；这不是像素视觉或科学内容验收。本批通过与原生 ZIP 入口相同的 HTTP 操作完成二进制导入，**未重复实测文件选择器**；此前入口见[原生上传验收](../flow-skill-native-upload/RESULTS.zh-CN.md)。

独立复核发现的伪 PNG 压缩流和动画 PNG 两处阻断已修复并按原样本复查通过。其余 PR01–14 缺口和前端布局继续保留。机器身份、摘要与验证结果集中见[单份证据](evidence.json)；原 ZIP、运行库和浏览器临时状态留在本机忽略目录。

验证：全量回归仅技能管理页两处旧文案断言失败；修复后相关 UI 8/8、技能 Unit/HTTP 6/6 通过，没有重跑无关全量。最终隔离干净安装、构建和类型检查通过，465 个产物；独立 Astra 复核的两项阻断均已关闭。本批不新增产品依赖，原工作区 12 处在途改动保持未暂存。
