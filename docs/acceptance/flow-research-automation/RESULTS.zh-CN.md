# 明确授权后的有界科研续接

本批将新授权的主会话串联为“私有实现 → 本机开发测试 → 结果回读 → 额度内修正或本地实验”。开发测试回读同时返回精确批准状态、期限、提交资格与阻断原因；合法的人类批准可恢复当时绑定的开发测试提交，已过期清单不会延长或重放。

## 固定验收条件

1. 只有明确接受新科研范围后的真实主会话输入可建立任务链。旧完全访问、子任务、普通通知和历史任务不自动获得此权限。
2. 每条链最多提交 3 次开发测试、2 次 local/可信示例 Run、6 次模型续接，持续 2 小时；同一时刻最多一个未终结计算。重复通知、查询和后续真实输入不得刷新额度。
3. 开发测试绑定已核验的本机 Docker 目标与固定沙箱；实验绑定既有合法来源、不可变配置和运行合同。自动续接不得提交别的根会话、旧人工批准、远端计算或任意新运行合同。
4. 终态结果和完整归档可触发有限续接；撤权、到期、未知状态、归档不完整、模型/来源变化或宿主租约失效阻止新效果。独立审查、团队启用、正式整合、发布、删除和凭据仍保留原批准边界。
5. 普通与仅宿主访问会话不创建科研租约；第二宿主不能抢占、消费或改动另一宿主的科研通知。服务停止后旧链永久失效，历史冻结记录仍可回读。

## 实际验证

- 初始验收测试 2/2 失败；实现后相关检查通过。独立复核发现旧批准绕过链额度及提交资格回读不一致，固定复现 3/3 失败，修正后相关 66/66 通过。
- 首轮集成全量 1449 项：1421 通过、4 失败、24 跳过。4 个失败为新增租约影响旧技能/备份行为及旧提示断言。修正生命周期后原相关组 20/20、租约与边界集 45/45、真实 Pi SDK 相关组 19/19 通过；原技能/备份测试未削弱。
- 修正后根目录全量 1458 项：1433 通过、1 失败、24 跳过。唯一失败来自另一批导航新源码与共享旧前端产物组合。统一重建后，原断言未修改，受影响导航、会话历史、右栏、滚动及权限界面 57/57 通过。原全量仍记录为失败，不以局部结果改写日志；未重复未受影响的全量检查。
- 当前组合版本实体构建、隔离干净安装、构建和类型检查通过；634 个发布文件逐字节一致。
- 实际本机 Docker 执行覆盖失败/完整归档 → 新冻结来源 → 成功/完整归档；可信示例父/配置子实验成功，终态通知各一次。实际 local 运行与独立 supervisor 中途撤权分别得到 succeeded 和 failed/invalid。
- 使用锁定版本 Pi SDK、真实 worker/bootstrap、技能绑定及原生会话持久化，对接固定本机 SSE 供应商：5 次 HTTP 请求，其中 2 次自动请求。IPC 固定响应夹具另作调度验证；没有调用外部付费模型。

独立 Astra 复核针对固定 33 文件快照及必要修正完成，无未关闭阻断；请求档位见机器记录。非阻断待办：普通只读 agent 查询人工已批准开发清单时，`canSubmit` 尚未反映会话只读上限；实际提交仍被权限检查拒绝，此项仅静态确认。原始日志、隔离夹具和浏览器诊断留在 `.validation/autonomy-flow-20261009/`，数据库、原生会话、认证文件和完整日志不纳入交付。

## 使用与限制

旧完全访问须撤销、重新启用并接受新弹窗范围，再发送新任务。此范围按任务固定额度；服务重启需要重新启用。原有过期任务与私有研究记录保持原状，不会补跑。

Chrome 新会话与隔离本机页面遭遇 `ERR_BLOCKED_BY_CLIENT`，原标签也与另一批工作并行使用，因此本批新增权限弹窗的浏览器操作验收未完成，未绕过浏览器保护或自动激活生产科研权限。权限请求与文案经组件检查，执行链经真实 Pi SDK 与本机计算验证。24 项既有环境跳过保留；外部模型自主判断质量、真实远端资源与无限自主科研不在本批验收内。
