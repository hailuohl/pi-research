# 所有新对话创建时自动绑定技能

普通主会话、CLI 创建的会话、对话分支和系统助手会话在创建记录时即固定技能包，不再等到第一次模型启动或手动选择。技能正文仍按需读取，不会一次加载全部资源。

验收条件：

1. 新建主会话、分支和助手会话立即返回持久化的技能版本，无需手动选择或启动模型。
2. 项目默认值更新不改已有绑定；尚未启动的主会话仍可显式选择；助手重试沿用原尝试版本。
3. 已准备的 Git 工作区保留原绑定；缺失、冲突或项目/任务/团队/角色错配先于预算消费被拒绝。
4. 重开保留绑定；现有权限、角色和未知历史拒绝规则保持，不批量迁移历史会话。

实现复用 SessionService、SkillService 和现有启动预检。在同一事务内读取项目默认并写入会话。任务调度先核对已准备会话，再预检和占用预算，后续更新不覆盖其版本。

前一批 statsmodels/scikit-learn 方法包 `6a24cca1c370257471bff9896d31f5e78d5ef313c29d7172e32d1055189b9be9` 已配置给工作台原有 5 个活跃项目。真实回归比较与方法吸纳证据沿用 [回归方法验收](../flow-regression-libraries-20261021/RESULT.md)，不重复安装或运行该科学实验。
