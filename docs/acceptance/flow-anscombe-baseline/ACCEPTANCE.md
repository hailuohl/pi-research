# 本批验收：固定公开数据的四组回归基线

范围：以 R 官方 `datasets::anscombe` 源文件为固定数据，复现四组描述统计、最小二乘直线和散点图；走一次正式 Docker Run 的准备、单独批准、提交和结果回查。不推断原论文的其他结论，不修改产品权限或前端布局。

1. **固定来源与输入。** 保留官方 `anscombe.R` 的来源 URL、SHA-256 和原始字节；从其八个数值列得到恰好四组各 11 个 `(x,y)`，运行快照能回查这份输入及基线程序。来源摘要不符或列数、行数不符时停止，不生成科研结果。
2. **批准后真实运行。** 未批准的 Run 意图提交失败且不创建 Run；批准固定镜像、命令、输入摘要和预期产物后，仅提交一次正式 Docker Run。归档的 `metrics.json` 报告四组各 11 点，`mean(x)` 为 9，`mean(y)` 在 7.49–7.51，OLS 斜率在 0.49–0.51、截距在 2.9–3.1、相关系数在 0.80–0.83；四格 `quartet.svg` 各含 11 个散点。结果只能称为此固定数据的数值与可视化复现。
3. **越界与失败。** 将未批准意图提交和更改已固定来源的尝试都拒绝；输出缺失或运行失败不得标记为完整成功。实际 Docker 只验本批成功关键路径一次，失败边界优先复用已有相关测试或在启动前验证。
4. **历史保留。** 关闭并重开控制对象、刷新工作台后，同一 Run 的状态、指标、输入快照及产物摘要仍可回查；验收克隆中的既有 PMC 报告和非设置记录保持原值。

环境缺失的验证可按用户要求跳过，但记录具体未验证项；不以跳过冒充通过。基线程序由验收夹具提供，不宣称由本轮 Pi 生成。
