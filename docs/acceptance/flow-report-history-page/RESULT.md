# 报告历史有界分页

所有者现在可调用后端 `report_list`，按项目与稳定游标读取最多 100 条报告摘要，并用 `report_inspect` 回查选中报告的当前有效性与固定引用。旧报告的标题和格式版本沿用现有回退规则；列表不展开正文、绑定清单或宿主路径。

剩余工作：旧项目总览响应仍含完整报告列表；前端改用新入口及布局重构留待后续。本批仅完成 PR07 的这条后端历史读取流程。独立复核指出的非阻断操作入口负例测试覆盖可在后续补齐，不临时扩批。

本机 HTTP 验收从实际 Wine 数据读取 5 份报告，页大小 2，得到 `2 → 2 → 1` 且末页结束；选中第二页报告，`report_inspect` 返回 `verified/current` 与 57 条固定引用。跨项目隔离、非法游标和超限页被验证；关闭重开后同一游标返回同一页。原 8 条报告/Run 记录和 5 份报告 Artifact 保持不变，未新增报告、Run、模型或连接器调用。机器证据见 [evidence.json](evidence.json)，原始日志保留在本地 `.validation`。

开发相关检查 13 项通过；集中回归 877 项中 854 通过、23 跳过、0 失败。干净构建 471 个文件一致，独立 Sol 复核无阻断。本批只验后端，未启动 Pi、Docker 或浏览器。
