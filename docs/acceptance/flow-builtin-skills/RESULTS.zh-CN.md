真实子进程 IPC 完成旧包在途读取、项目切新版、旧进程再次读取、新绑定读取新版，以及 Host 重开后原会话继续读取旧版。旧正文两次摘要一致，新正文不同；未知包在 fork 前失败，generation=0、占用槽位=0。该测试共 fork 3 次，**没有 Pi SDK 或供应商请求**，不称为真实模型验收。[IPC 证据](ipc-evidence.json)区分这些范围。
