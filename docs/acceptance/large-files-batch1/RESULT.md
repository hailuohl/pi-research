## 本批验收

1. 普通文本/数据原件默认单文件 512 MiB，通过 `PI_RESEARCH_MAX_FILE_BYTES` 配置；非法配置和超限明确失败。
2. 流式导入与完整摘要校验；分页读取 I/O/内存有界，中文、emoji、BOM、超长单行保持原始字节。
3. 每页校验 owner、项目生命周期、固定摘要与命中数据块；跨项目、损坏、路径替换不放行。
4. 中断、无效 UTF-8、幂等冲突不发布半成品；已有文档不被重传覆盖。
5. 新接口明确 `utf8-byte` 游标；关闭重开后仍可继续同一固定来源。旧 JSON 入口和媒体限制保持各自明确语义。
