# 模型管理状态的备份与恢复

新建备份在受校验的清单中保存脱密模型目录：供应商及模型 ID、定义、排序、启停状态、永久删除标记和管理版本。API Key、原生认证、环境凭据、保存请求回执不进入该目录快照；原运行凭据文件仍排除。SQL 中不含密钥、提示或模型正文的模型测试摘要，以及会话、原生请求和续跑材料的历史保持原样。

恢复只重建一份运行权威文件 `model-connections.json`。原已管理连接进入“需要重新保存凭据”状态；在用户显式保存非空 API Key 前，默认模型不可用、选择目录不可选、Worker／模型测试／原生请求均拒绝外发，也不回退到环境变量或原生认证。重新保存凭据保留模型定义、排序、停用及删除标记，并增加凭据版本，使旧测试和旧原生授权不能因恢复而重新生效。历史控制条目保持原有语义，永久删除不能复活。

早期备份没有模型目录快照，仍按其既有格式恢复；它们无法恢复当时未纳入备份的管理定义、停用状态或删除标记。不能把旧备份的缺失目录解释成已保留这些状态。

管理保存对整个状态统一校验，包含历史控制条目的供应商总数最多 20、模型总数最多 100、文件最多 512 KiB。超限或结构非法时不修改原文件及版本。原生 HTTP 仅在本地传输已确认结束后允许备份其未知远端结果；正在传输或未确认结束的请求仍阻止备份。
