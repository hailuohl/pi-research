2026-10-02。原“研究会话”导航按钮改为“新建会话”，调用现有创建接口，在当前项目打开新对话。原目录右上角的新建按钮改为原生分类下拉框：“活跃 / 已归档 / 全部”，默认活跃。沿用本地 OpenResearch 的分类语义，活跃包含所有未归档会话。

验收条件：

1. 创建成功打开新会话并关闭手机导航；没有项目或操作中禁用。失败、项目切换后的迟到响应及卸载不会覆盖原对话。
2. 分类在服务端游标和数量限制之前过滤，与搜索及角色筛选相交；旧客户端不传分类时继续返回全部。
3. 切换分类重置分页并保留当前打开的对话，不向目录插入不属于该分类的当前会话。只有创建成功才主动切回活跃；记录和归档状态保留。
4. 相关检查、集中回归、干净构建、独立复核与浏览器关键路径通过。
