# 研究计划保存的未知字段诊断

上游模型在 `status: "ready"` 之外添加了独立的 `ready` 字段，严格输入校验正确拒绝该调用。未知字段名不能进入公开诊断，原错误因此退化为通用提示；移除额外字段后的调用已成功保存。本次没有重试真实保存或修改原研究记录。

共享 schema 校验现在将“未知字段”定位到包含该字段的对象，例如 `$.input: 未知字段`。输入仍被拒绝，未知字段名和值仍不公开。没有修改工具参数、批准条件、证据检查、版本或历史规则。

新增回归覆盖外层、input 及步骤对象中的普通和含点、冒号、换行、括号的未知字段。原代码下回归失败；修复后真实 Pi SDK 的 HTTP 夹具同时检查安全提示、零写入、固定批准、修订历史及重开。原有隐私断言保留。

验证在基线提交加本批变更的独立快照中进行，以排除共享工作区其他在途改动。实际检查结果、代码锚点和模型配置记录见 EVIDENCE.json；原始数据和日志保留在忽略目录，不纳入提交。
