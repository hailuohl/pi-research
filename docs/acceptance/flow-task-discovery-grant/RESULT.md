# Task DiscoveryGrant：单项 Crossref 发现

所有者现在可为尚未派发的 `literature` Task 固定一项 Crossref 默认关键词检索、一次 HTTP 请求、字节上限和有效期。Grant 与 Team 分别批准后，真实任务尝试才取得授权；请求计次、检索结果和原生会话均保留原身份。旧主协调会话 Grant 仍可使用原入口。

本批后端验收逐项通过：准备与两次审批前无模型或网络副作用；真实 Pi 完成任务，只有一条成功的 Crossref 请求且 Grant 额度归零；越界、旧检索入口、失效及授权标记全部丢失均在外发前拒绝；关闭服务并重开数据后，任务、授权、调用、结果及旧项目文件保持可读。Crossref 返回的唯一命中与查询 DOI 不同，任务明确记录它只是元数据匹配，未将其当作目标论文或科学证据。

集成回归通过（845 通过、22 项环境可选检查跳过），干净构建与当前产物一致。独立权限复核发现的准备入口互斥字段问题已修复并补上正式操作入口回归。机器证据见 [evidence.json](evidence.json)；原始运行日志留在本地 `.validation`，未复制进仓库。前端和浏览器不在本批验收范围。

剩余工作沿原 PR01–14 计划继续：RunGrant、其他 DiscoveryGrant 用例，以及缺少外部主机的远端验收。本批没有扩展到其他任务角色或来源。
