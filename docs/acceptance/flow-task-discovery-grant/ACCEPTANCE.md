# 本批验收：一项文献子任务的有限发现授权

范围：所有者为尚未派发的一项 literature 子任务固定一个 Crossref 检索词、一次 HTTP 请求、响应字节上限和有效期；沿用现有 Team、DiscoveryGrant、ConnectorCall、独立审批与文献结果，不给该子任务扩大其他来源、模型、计算或发布权限。旧主协调会话 Grant 和既有任务历史必须兼容。

1. **固定授权到任务。** 准备/批准/激活时绑定确切项目、Team 计划、TaskSpec、角色、模型及检索条件；这些步骤不启动模型或外发请求。团队另行批准后，该 literature 任务的新尝试从原任务身份取得 Grant，不把主协调会话的其他权限继承给它。
2. **真实受限使用。** 获准任务只能对固定 Crossref 查询发出一次实际 HTTP 请求，原请求、结果和永久计次有一致的 Grant 引用；可按原出处回查命中。真实 Pi 若完成任务，则保存原生终态与结构化结果；网络/模型失败如实留证，不重复提交同一请求。
3. **越界与失败。** 指定任务省略 Grant 引用、改变查询/来源/额度，其他任务或会话借用该 Grant，旧检索入口绕过，撤销/到期/原 Team 批准失效或已耗尽后新外发，均应在外部副作用前拒绝。失败或未知请求仍占额度；既有主协调 Grant 路径保持原语义。
4. **恢复与历史。** 关闭重开控制对象后，任务、尝试、授权、请求回执和历史结果按原 ID 可读；重复事件/超时只对账同一请求，不自动再发。旧项目业务记录与原生会话字节保留。开发只跑相关检查，代码集成后集中一次全量回归、干净构建与独立权限复核；真实 Pi/HTTP 只验本批关键路径，前端不验。

本批只覆盖一项有界 Crossref 任务，不暗示其他角色/来源已改为强制 Task 级 Grant；若现有全局 Task 网络权限与此授权目标冲突，先定位并修复明确阻断，不临时扩成全部角色迁移。
