# 固定双模型 Run 的方法与结果分析（Run ff024aab-250e-4c84-9ca7-beff8a52ab48）

## 1. 分析目标与材料

本报告基于任务固定的 8 份输入 artifact 实际读取：预定方案（predeclared-protocol.md）、原始数据字典（winequality.names）、Run 原始产物（split.json、predictions.csv、diagnostics.json、metrics.json、environment.json）以及另行执行的独立 QR 审计（independent-qr-audit.json）。全程未进行新的计算、拟合、网络访问或新 Run。

分析目标（来自预定方案原文）：在 UCI 红酒质量数据（Cortez et al., 2009，CC BY 4.0）上，以全部 11 个理化特征为预测变量、quality 为数值响应，比较 degree 1（线性）与 degree 2（含交互项）两个多项式回归模型在同一固定划分上的测试集行加权 RMSE。

## 2. 数据与实际划分

- 数据：红酒 1599 行、11 输入变量 + quality（0–10 评分），字典声明无缺失值（"Missing Attribute Values: None"）。quality 为感官评分（酒类专家至少 3 次评估的中位数；原文没有据此确定不同专家的人数）；将其作等距数值响应是一项分析选择，不是序数模型推断。
- 分组规则：程序按**完全相同的 11 维预测向量**分组（共 1359 组），相对唯一完整记录，有 240 行重复（含相同 quality）。以相同预测向量为分组是本次的防泄漏规则；这不证明这些行是同一酒样身份，也不证明组间独立。
- 实际划分（split.json + QR 审计交叉核对一致）：seed 20261021，按组 70/30 单次划分；1599 行 = 训练 1124 行（951 组）+ 测试 475 行（408 组）；跨划分的预测向量组数 = 0，即没有任何预测向量组同时出现在训练与测试集合。两个模型使用完全相同的行与相同划分。
- 环境固定（environment.json）：Python 3.12.14，scikit-learn 1.9.1、statsmodels 0.15.0、numpy 2.5.3、scipy 1.18.1、pandas 3.0.6；记录了输入与源码的 SHA-256。

## 3. 两个模型的结果（本项目 Run 实测）

metrics.json（Run 实际写入的三个平铺有限数值，单位为评分点）：

| 指标 | 值（评分单位） |
|---|---|
| baseline_rmse（degree 1，测试行加权 RMSE） | 0.6251565814631911 |
| candidate_rmse（degree 2，测试行加权 RMSE） | 0.6606749409280763 |
| rmse_gain（线性 − 二次） | −0.03551835946488524 |

增益为负：在该单一固定划分上，degree 2 的测试 RMSE 比 degree 1 高约 0.036 评分点。训练残差 RMSE 则为 degree 1 = 0.6557、degree 2 = 0.6074（diagnostics.json），即二次模型训练拟合更好但测试更差——与过拟合方向一致，但这是一个描述性观察，不构成正式的过拟合检验。

设计矩阵与诊断（diagnostics.json，Run 实测）：
- degree 1：12 参数，rank 12（满秩），条件数 6.94，残差 df 1112，最大杠杆 0.144，最大 Cook 距离 0.123。
- degree 2：78 参数，rank 78（满秩），条件数 123.16，残差 df 1046，最大杠杆 0.915，最大 Cook 距离 0.294。
- 条件数从 6.94 增至 123.16，约为原来的 18 倍；本方案未预定“严重病态”的阈值。训练设计矩阵的最大杠杆值为 0.915。另一个独立观察是，测试记录 row-1575 的二次预测约为 1.63（观测 6.0）。归档没有给出该测试记录的杠杆量或最大训练杠杆对应的行ID，不能将两者关联或据此判断该测试误差的成因。
- 两个模型均未删除任何观测（符合方案"不自动移除观测"）。

## 4. 同设计矩阵数值交叉核对

scikit-learn Pipeline（StandardScaler 仅在训练行上拟合 → PolynomialFeatures → LinearRegression）与 statsmodels OLS（同一变换设计 + 显式截距 + 相同训练响应）的核对结果：
- diagnostics.json：跨库预测最大绝对误差 degree 1 = 5.33e-15，degree 2 = 9.77e-14，均在方案容差（rtol=1e-8, atol=1e-9）内。代码另对系数执行同容差断言，但未归档系数最大差。
- 独立 QR 审计（另行执行，非本 Run 内部）：QR 参考解的 RMSE = [0.6251565814631911, 0.6606749409280758]，与 metrics.json 在声明的数值容差内一致；预测最大绝对误差 = [3.55e-15, 2.75e-14]；对被篡改预测的注入测试被正确拒绝（corrupted_prediction_rejected = true）；审计还独立复核了行数、划分组数与跨划分组为 0。

结论（实现层）：同一设计矩阵下两个库及独立 QR 分解相互一致，数值实现可信。**这只证明实现层数值一致性，不构成独立的科学证据，也不能替代对设计、假设或解释的审查。**

## 5. 材料间矛盾检查

逐项核对后未发现矛盾：
- split.json 与 QR 审计的行数/组数/划分完全一致（1599/1124/475；951/408；跨划分组 0）。
- metrics.json 与 QR 审计 RMSE 一致（二次值末位 0.6606749409280758 vs 0.6606749409280763，浮点表示差异，远小于任何实质容差）。
- 预测 CSV 的行 ID 与 split.json 的 test_row_ids 集合一致（475 行）。
- 预定方案声明与实际产物（metrics 仅三个平铺有限数值、声明五类产物、无调参/无第二种子）相符。
- 训练均值/尺度（diagnostics.json）与数据字典 11 特征顺序一致（如 alcohol 训练均值 10.42 与数据集常识量级相符）。
- 数据字典提到原论文 SVM 结果最好；本实验不是该论文复现，方案也明确声明这一点，不构成矛盾。

两个应分开保留的观察：predictions.csv 中测试记录 row-1575 的二次预测约为 1.63；diagnostics.json 中二次模型的训练最大杠杆为 0.915。当前材料没有建立两者的个体对应或因果联系。

## 6. 计算、科学推断与未验证项的区分

**已实测/已核对（计算层）**：两个模型在同一固定划分上的测试 RMSE 与增益（三个数值）；划分行/组数与组不跨集合；两个设计矩阵满秩及条件数、杠杆、Cook 距离；scikit-learn、statsmodels 与独立 QR 三方数值一致；运行环境与数据/源码哈希。

**描述性观察**：二次模型训练 RMSE 更低、测试 RMSE 更高，方向上与过拟合一致；degree 2 存在高杠杆点及个别极端预测。这些是观察，不是经检验的结论。

**科学推断（本报告的解释，非实测）**：在本次划分上二次模型未带来行加权 RMSE 改善，点估计反而更差约 0.036 评分点；结合参数量从 12 增至 78、条件数升高，可解释为额外非线性容量在此样本量与划分下未获得泛化收益。这是基于上述证据的解释（Claim 候选），未做正式模型选择检验。

**明确未验证/不做的主张**（方案与 QR 审计均如此声明）：无 iid 置信区间、无显著性/等价性检验、无因果或外部泛化主张；单一种子单一划分，划分敏感性未评估；序数响应的等距假设未检验；相同预测向量分组是防泄漏规则，**不证明同一酒样身份或组间独立**；HC3 稳健标准误未报告；未做特征选择（字典本身提示特征可能相关，原论文建议特征选择，本实验按方案未做）。此外，本报告对 predictions.csv 仅做浏览式核对（行数、ID 集合、极端值观察），未逐行重算 RMSE（QR 审计已独立完成该复算）。

## 7. 限制

1. 单一 70/30 组划分、单一随机种子：结果只对该划分成立，无法区分"二次项在该数据上无增益"与"该划分恰好不利"。
2. 行加权 RMSE 使多行同组记录被重复计入；组级（408 组）评价会得到不同权重，两种口径不可互换。
3. quality 是序数感官评分的中位数；等距数值化是约定，模型系数不能直接解释为序数效应。
4. 库间一致与 QR 审计验证的是数值实现，不验证研究设计、假设或科学结论（QR 审计自述 inference: "not_assessed: clustered/repeated test records, single fixed split"）。
5. 本分析是文本审查，未重新执行任何代码。

## 8. 结论

本次固定 Run 在实现层可信：划分防泄漏规则落实（跨划分预测向量组 = 0），三方数值交叉核验一致，产物完整。实测结果为：degree 1 测试 RMSE = 0.6252、degree 2 = 0.6607、增益 = −0.0355 评分点（本划分）。在该固定划分上，加入二次与交互项未改善行加权测试 RMSE，点估计方向不利于二次模型。由于无区间/显著性推断、单种子单划分、序数响应等限制，本结果不支持"二次模型劣于线性"的一般性结论，也不支持任何因果或外推主张。
