# 环境变量与本地 Pi Agent

本批只完成“设置变量 → 新启动的本地任务使用 → 更新/删除与历史回查”流程。资源与调度页面及所有跳转已移除；旧浏览器标签自动转到环境页面。无需先创建项目。环境页沿用现有界面，参考 OpenResearch 的变量列表、遮罩值和新增/删除交互。

验收：
1. Pi Worker 仍只在本机 fork；宿主 Worker/模型 HTTP 上限为 null，旧限额不再阻止派发。项目、团队、身份、租约、未知占位和图片权限保护保留。
2. 变量可新增、替换、删除；GET 只回元数据。大写名称、非空值、保留变量、版本冲突、幂等重试、重开均经过验证。值写入本机独立私密 JSON，不写 SQLite 事件或实验契约。
3. 新本地 Pi 主/子 Worker、已授权宿主命令和正式本地 Run 使用变量；Docker/SSH 不自动接收。原模型连接功能仍是另一个在途批次，不纳入本次提交。
4. 删除或轮换后，私密历史仅用于旧值遮罩。UTF-8、跨片段、截断后的密钥前缀、agent 创建的新文本产物均验证；产物按处理后的字节计算摘要。科学指标数字与用户导入的原件保留。
5. 备份排除环境配置、本地作业原始输出/工作/临时文件/日志/启动配置，保留目录、恢复回执和已遮罩归档。恢复后从归档回查日志。原生 Pi JSONL 的正文若实际含敏感值，备份明确拒绝，保留原文件与引用。
