# 普通聊天统一附件

2026-10-08。本批移除独立「原件分析 / 原生联网」入口，把支持的模型文件输入接入普通聊天附件。代码验收完成；现有 4794 服务的重启被自动审批拦截，仍运行旧后端，现场生效待重启。

## 验收与实际行为

1. Chat 页头不再挂载独立原生请求面板，模型管理不再展示原生联网开关。独立请求的新建、批准、执行及旧视频上传接口返回 410；历史读取、取消和原有记录保留。
2. 附件选择器和服务器共用当前模型能力范围。TXT/MD 可用；PNG/JPEG/WebP/GIF、PDF、MP4 需明确模型声明及已接入的协议支持。旧本地目录明确声明的图片能力可用；未确认的文件能力只开放 TXT/MD，并提示配置。最多 5 件；文本单件最多 32 MiB，原生文件单件及实际上下文合计最多 20 MiB。
3. 支持的原件随普通 Pi 对话发送，保留历史与工具调用。来源限定本项目用户上传资料，校验签名、摘要、大小；每次实际文件 HTTP 前重新核验权限 epoch、hostEpoch、模型目录及原件。既有原文/文稿页图授权守卫保留。
4. 输入末尾的宿主标记只绑定固定清单，正文复制旧标记不会授权文件。合成分支历史的文件来源在投递前冻结，重开与显式重试恢复同一范围；分支不复制旧聚合字段，失败/未投递来源不自动外发。
5. 上传或发送失败保留附件。旧缺省模式 PDF 及其重试仍只提供需解析元数据，不自动升级整文件外发；历史资料和原件不删除。
