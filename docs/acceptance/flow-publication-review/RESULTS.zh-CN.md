# 固定论文审查、报告与成果包

现在可在成功构建旁选择协调会话和输入证据，准备并单独批准论文审查。审查固定到精确修订、sourceDigest、构建/PDF、输入及批准身份；新报告自动纳入该构建的全部关联审查，并在成果包中提供独立的 `reviews/<reviewId>.json`。接受、拒绝、争议和未完成分别保留，没有审查则明确标为未审查；旧普通 reviewer 任务不会自动变成机器绑定。

新报告生成后新增或改变审查，会使该报告需要更新；撤销输入或批准会阻止新报告/新导出。历史正文和已生成包保留，旧格式报告继续按原语义读取。Reviewer 只读固定清单中的原件，不继承协调会话的实验源码，也不能从一个指标证据扩大到整个 Run 的读取权限。意见不直接创建科学 Claim。
