# arXiv 指定 v2 原 PDF 解析：本批验收条件

1. 在隔离复制的既有项目中，所有者选定已取得的 `1706.03762v2` 原 PDF，配置当前固定解析镜像，单独准备、批准并提交；真实 Docker 生成成功且完整的物理页、原页图和文本，结果绑定原文摘要与请求版本 2。只有解析文本确有匹配标记时才宣称版本内容核验。
2. 未批准提交、把 v1 解析结果冒作 v2 页证据、跨项目读取均被拒；失败不能产生可用 v2 页证据或额外原件获取。
3. 旧 v1 原件、解析结果与页证据保持原身份和原字节；v2 结果在重开与浏览器刷新后仍可从相同文档版本回查，不重跑既有任务。
4. 本批不发新的文献来源请求、不调用 Pi，不把 PDF 页解析称为科学结论；表、图及阅读顺序按当前质量字段如实展示。
