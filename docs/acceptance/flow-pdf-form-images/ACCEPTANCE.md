# PDF Form 内嵌栅格对象定位：本批验收条件

1. 所有者对含平移、缩放及旋转 Form 的固定原 PDF 明确准备、批准、提交新版解析；真实 Docker 输出的物理页候选框覆盖同页图的可见栅格内容，展开裁剪与原页一致。页面直接图片仍可定位，均不声称科学 Figure 或图注。
2. 非有限、越界或过深的对象变换不能发布错位的可用候选；篡改候选页内边界或页图摘要不能形成成功解析结果。
3. 旧 v1/v2 解析结果、页证据和报告保持冻结来源且可回查；进行中的旧 profile 作业不重启、不改用新版镜像。
4. 未批准或跨项目读取仍按原边界拒绝；刷新后可从新版固定结果重开相同物理页和候选，旧版空候选不被追认成新版检测结果。
