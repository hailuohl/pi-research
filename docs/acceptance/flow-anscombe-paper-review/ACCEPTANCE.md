# 本批验收：真实 Pi 独立审查固定 Anscombe 文稿

范围：只针对上一批已归档的两页 PDF 所属固定文稿构建。独立 reviewer 可读取精确 TeX、图形来源、两项 Run 指标/逐点预测与构建日志，提交带证据引用的 accept、reject 或 disputed；任何一种真实结论都保留，不以模型投票代替科研判断。另生成反映本次审查集合的新报告和离线包，不改写旧报告。

1. **准备不执行。** 用户选择固定构建结果和确切输入证据后，系统冻结修订、PDF 摘要、构建批准、来源、必需证据及独立 reviewer 任务。单纯准备不得启动模型、Run、开发作业或编译；未批准不得激活审查。
2. **一次真实独立审查。** 经单独批准后，只启动一个新 reviewer 会话，使用已配置的智谱模型，实际读取固定 TeX、原始指标/逐点预测及日志，并对全部必需证据给出引用。结构化结果与原生会话终态分别记录；若任务失败、证据不足或模型不可用，不补造接受意见，不因观察超时重启同一任务。审查不能读取未授权私有来源或创建科学 Claim。
3. **新旧交付边界。** 完成的审查（接受、拒绝或争议均如实标注）必须绑定精确文稿结果。新报告和包含该审查的冻结 JSON、两项 Run、可编辑 TeX、图与 PDF；旧报告/旧包原字节不变，新增审查后旧报告的新导出须按既有有效性规则拒绝。缺批准或来源失效不能生成新的有效报告。
4. **重开与历史。** 关闭重开控制对象后，通过后端按原 ID 读取同一审查、verdict、TaskAttempt、输入摘要和新旧报告状态。隔离副本中的既有 Anscombe 结果和旧 PMC 报告保留；真实 Pi 只验本批关键路径一次。缺失环境按用户要求跳过并注明未验，不把模拟结果冒充真实调用。

前端与浏览器验收依用户最新要求暂缓；本批不追加数值运行、图形作业或论文编译。
