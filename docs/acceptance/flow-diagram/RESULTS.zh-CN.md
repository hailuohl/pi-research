1. 新的隔离项目会话显式选择内置 `pi-research-figures`；真实 Pi 读取固定 `SKILL.md` 和 `references/diagram.md`，只在私有工作区写生成源码，不自行运行或批准计算。
2. 未批准的固定开发任务不得启动；仅由用户批准 `python`、固定镜像、无网络与资源上限、声明的图形产物，再提交一次。越界文件或失效来源拒绝，且不出现第二个容器。
3. Docker 实际生成可打开的结构图，独立核对节点、箭头、图例/限制说明与产物字节；保留固定源码、执行回执、摘要和真实终态，不能把示意图称为科研结果。
4. 关闭本批隔离服务后重开，仍能回查相同会话、审批、作业、图形及源码摘要；浏览器刷新后可找到并下载固定产物。

本批只验证这一条 diagram 流程。SSH 需要授权远端目标与完整的持久监管协议，留在 PR13；不把本机连通性当作远端验收。前端布局及其他待办不纳入本批。
