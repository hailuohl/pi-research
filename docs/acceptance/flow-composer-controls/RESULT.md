# 输入框来源、附件与模型选择

2026-10-02。按用户提供的OpenResearch截图安排输入框：左下来源与回形针附件，右下模型/思考等级及发送。保留多智能体开关，使用现有暖白酒红主题及固定版本Lucide图标。设置页保存多个非密钥模型组合供选择，并设为新会话默认。

验收条件：

1. 模型设置实际持久化、重开可读；公开DTO只含供应商、模型ID、思考级别，不加入密钥。
2. 当前交互主会话从已保存模型中选择；事务内拒绝运行/排队输入、未退出Worker、助手、归档、固定授权或非终态协作计划，不改批准模型、旧消息或原生历史。
3. 来源复用项目连接器开关，与现有检索实际共享；保存失败保留选择和聊天草稿，打开或启用不自动发外部请求。
4. PDF/TXT/MD真实归档后绑定固定消息描述，文本可受控分页读取；上传/发送失败及期间新输入保留，队列修改、取消、重试、分支保留引用和原件。
5. 桌面左/右控件与手机两排布局可用，原Enter/IME、自动排队、立即/编辑/删除保留。

附件继续沿用原有owner项目归档共享范围，不新建会话私密存储。新读取工具仅接受当前交互主会话已投递用户消息的显式owner-upload原件，校验项目、固定摘要及generation/lease，禁止助手、自动唤醒、待发/删除消息和connector/PMC/解析派生来源。PDF只返回需要显式解析，不自动读取受限语料或运行解析器。分支是用户明确创建的项目内历史复制，引用保留；移除草稿chip不删除文档。
