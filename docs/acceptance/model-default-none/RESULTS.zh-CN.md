# none 映射与新会话默认档位 · 2026-10-09

旧全局默认为 GLM‑5.3 / `off`，该模型的 SDK 目录明确不支持关闭思考，设置提供 `low / high / max`、默认 `low`。此前 legacy 默认校验绕过档位检查，新建与空白复用原样继承 `off`，导致设置判可用而聊天菜单提示不可用。

## 本批结果

- 推荐配置中 `off` 的显示名统一为 `none`，内部 ID 与 Pi 档位仍为 `off`。不添加第二个同义档位；不支持 `off` 的模型不补 `none`；已保存自定义标签和 ID 保留。
- HTTP 新建、默认保存及模型切换使用同一模型目录准备与校验。新建流程只把非法档位校正为该模型自己的默认档位，不更换供应商或模型身份。
- SDK 准备在事务外执行，写入前复核目录版本、全局版本和原生目录摘要。全局默认修正与创建/空白复用在同一事务中提交；重复请求复用原幂等回执。
- 已有空白会话仍复用同一记录。任意消息、已启动状态或未退出 Worker 阻止复用；实际修改模型时额外阻止冻结授权、来源及历史绑定。合法固定授权空白保持字段和版本不变。
- 响应丢失重试保持原请求与幂等键；确认会话 Row 立即传播，后续刷新失败仍显示已确认档位。双空模型允许先创建后配置，界面提示选择模型。
- 旧 Pi 原生配置继续从本地目录读取，临时 legacy 条目不被误判为待恢复受管凭据；受管连接的缺凭据与恢复限制保留。

## 验证

完整隔离回归首次运行：1493 项，1468 通过、24 环境跳过、1 失败。唯一失败暴露旧式原生配置被误排除的兼容问题，已修正；随后 100 项受影响检查全部通过，包括该原失败测试、真实 Pi 本地附件/模型调用、恢复凭据保护、模型切换和新建流程。其余已通过证据按本批规则复用，没有伪称再次运行完整回归。

最终干净安装、构建与类型检查通过，635 个构建文件一致。独立 Astra / xhigh 复核及必要补丁定向复查均无阻断。精简机器证据见 `evidence.json`，原始日志留在 `.validation/reasoning-default-20261009/`。

隔离浏览器验证原会话从 `off` 校正为 `low`，重复新建保持 3 条记录，历史及合法绑定会话保持原档位与版本；选择 GPT‑5.1 的 `none` 后保存为 `off`，刷新和再次新建保持该选择。两个模型滑轨宽度均为 286.666687px。真实固定 Pi Worker 的本地 Responses 请求确认 `reasoning.effort = none`。

实际 4794 预览已验证：原空白会话 ID 不变，GLM‑5.3 显示 `low`，全局默认同步为 `low`，未发送模型消息。原 5 个在途文件保持原 SHA256；其他会话的改动没有纳入本批。

## 限制

未调用外部付费模型；24 项可选 Docker、LaTeX 与 POSIX 检查按环境跳过。三个模型写入 HTTP 入口现在只接受无查询参数的 POST，仓内调用均使用 POST。未知 SDK 模型不自动猜测非法档位。

实施请求 Sol / high，单独 wire 回归请求 Luna / max，独立关键复核请求 Astra / xhigh；接口接受参数但运行时未回显。主会话模型与思考强度未调整。
