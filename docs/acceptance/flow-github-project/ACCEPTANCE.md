# 新项目可选 GitHub 源码同步

2026-10-07；基线 `8462973fe81e63d6b8fdfdfc686ea36a2f8518f4`。本批只完成项目源码的可选 GitHub 流程，GPU 另批；已有本地项目不自动开启上传。

## 验收条件

1. 新项目默认本地。设置显示当前电脑 Git/GitHub CLI 及 github.com 当前个人账号状态；未就绪时不能勾选上传，服务端同样检查。正常本地创建不依赖 GitHub 登录或网络。勾选文案明确创建私密仓库并同步后续已提交源码。
2. 仓库默认使用项目英文名或中文拼音，确定重名才按 `-1`、`-2` 递增。固定账号、仓库数值身份和私密性；账号切换、身份变化或不确定创建结果不静默改目标、不接管已有仓库、不重复盲建。
3. 创建请求、本地项目、固定初始快照与上传记录可幂等恢复；源代码提交同步只使用已完成受管操作的准确 SHA 和受管分支，核对全部待上传历史及来源，不上传应用数据库、会话、密钥或独立科研资料，不强推。成功须有远端准确 SHA 回查。
4. 网络失败、远端冲突、关闭同步、归档及重开均保留本地项目、快照和状态；未知结果先对账，失效授权不开始新外发。程序、账户及路径在各电脑重新解析，三平台相关检查单独记录。真实创建仓库和上传只由用户实际勾选触发，开发验证不创建无关远端测试仓库。

复用现有本地Git、快照、来源校验、幂等和审计。允许为准确中文转拼音引入固定版本 `pinyin-pro`（标准库没有对应功能）；不手写字典，不引入通用同步框架。原在途文件不改；前端仅增加本批明确要求的创建与设置入口。
