# 原生文件选择器：ZIP 技能上传、审阅与会话绑定

本批确认 PR11 一个此前未验的工作台入口：用户在**浏览器原生文件选择器**选取单个受限 ZIP，填写版本信息并提交，得到待审的不可变技能修订；页面逐份读取 `SKILL.md` 与资源后，用户批准、显式启用，并为新主会话选择该技能。预检通过但没有启动模型或计算。刷新后同一修订、摘要、批准、配置和会话固定 bundle 均可回查。

先在同一表单混选 ZIP 与普通文本，页面返回“ZIP 必须单独上传”，目录仍为空；改选单个 468 B ZIP 后才形成唯一修订。归档两份文本分别为 208/101 B，与本地输入逐字节及 SHA-256 一致；未知许可证保持未知，文本审阅没有授予脚本执行权限。验收在隔离本地项目进行，未上传用户附带的完整源码 ZIP，也未改 Wine 研究库。

本批没有产品代码改动，因此没有重复全量回归、干净构建或已验 Pi/Docker 路径。浏览器无 console error，持久库仅有一条修订、一条批准审阅、一条配置和一条空闲会话；模型、任务与 Run 记录均为零。独立只读复核无阻断。[机器证据](evidence.json)保留身份、摘要和观察边界；原始 ZIP、运行库与单张截图留在 `.validation/skill-native-upload/`。

证据限制：数据库不记录导入请求的浏览器来源，最终截图只显示会话选择和预检。原生文件选择及混选拒绝由本批现场浏览器操作确认；不将其说成可从数据库单独重演的事实。PR11 二进制资源、完整 diagram 执行器及原 PR01–14 其余范围继续推进；前端布局仍暂缓。
