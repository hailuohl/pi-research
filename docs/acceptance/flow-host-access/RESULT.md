# 本机完全访问就绪

基线：`0852c80b0326ef7ae52bf606db77850ecc2653e4`。用户从四档设计转为要求真实“完全访问”就绪；采用已说明的系统用户级本机可信执行，实际开启需在会话内明确确认。不提供同用户控制面隔离，不将 `osSandboxVerified` 改为真。

## 实际变化

主协调会话入口 → 必选范围确认 → 真正启用 → Pi 自定义 `host_execute` 经 Registry 调用真实进程/文件/网络 → 撤销。保持 builtin 关闭、其他角色/任务/唤醒无自动继承、已有固定范围授权会话不可用；授权绑定运行端和 epoch，重启需重开。输入工具栏位置保留，现有说明行容纳入口。原型“未就绪”说明也更新为正式工作台入口。

详细范围与与原隔离设计的区别见 [实施说明](../../design/permission-modes-2026-10-05/HOST-IMPLEMENTATION.zh-CN.md)。前三档仍是设计，不冒充已经实施的通用 effect 审批。

## 独立复核

独立 Astra 会话明确请求 xhigh；工具接受但运行时未回显，不冒称已核验模型/档位。主代理实施。新 spawn受线程数限制，沿用本任务的独立只读复核会话，不声称新建。
