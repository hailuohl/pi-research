# 固定比较结果进入图、可编辑文稿与离线包

新增可用能力：上一批 Anscombe 第 2 组的两项完整 Run 经单独批准的隔离图形作业，读取四件原始指标/预测产物，生成 [PNG 图](figure.png)和[逐点映射](figure-data.json)。这张图作为原产物绑定进[可编辑 TeX](main.tex)，另经单独批准的 XeLaTeX 构建得到[两页 PDF](document.pdf)。[固定报告](report.md)同时纳入已停止的研究活动、两项 Run、文稿及图形来源；[离线成果包](anscombe-paper.tar.gz)包含这些固定源文件和结果。

图中红色是 11 个实际点，蓝色是一阶留一预测，绿色是二阶留一预测。图形作业核对四个输入摘要、相同行次与实际坐标，并重算两项留一误差；它只证明本次固定产物的映射。[R 官方数据](https://search.r-project.org/R/refmans/datasets/html/anscombe.html)与 [Anscombe 1973 的 DOI](https://doi.org/10.1080/00031305.1973.10478966)用于来源定位，原论文全文未读。二阶/一阶留一误差的比较只限这 11 点，没有独立外部测试集。文稿由验收夹具撰写，未冒称 Pi 生成或科学审查通过；产品报告明确标记 `not-reviewed`、科研判断 `pending`。

审批与历史：未批准的图形作业和文稿构建提交均被拒。构建产物完整成功，两个 PDF 页图目视检查无裁切或编译诊断。报告 `verified/current`；成果包 **736,528 字节**，解包后 38 条目中的 36 个固定文件逐项通过长度与 SHA-256 校验，含图形脚本、四件输入、TeX、PNG、PDF、活动方案和两份 Run 快照。重开与浏览器刷新后仍能按原 ID 回查报告、文稿修订、构建与 Run；隔离副本中旧 PMC 报告保持 current，原有 107 条非设置记录摘要不变。

剩余工作：该文稿尚未经过产品内的独立论文审查；图形的固定来源与逐点数值是分别核验的，不把来源绑定自动当成科学正确性。绿色二阶点几乎与红色实测点重合，缩图时可按图例和逐点数据核查。其他 PR01–14 缺口继续按流程推进，SSH 缺主机时跳过实测；前端布局仍暂缓。

验证：本批真实 Docker 图形与编译各一次、浏览器关键路径一次；独立只读复核无阻断。相关作业/文稿/导出检查 **28 通过、0 失败、1 环境跳过**。产品源码未改，因此未重复已完成的全量回归和干净构建。精简机器摘要见 [evidence.json](evidence.json)，完整运行日志和隔离数据库留在本地 `.validation/anscombe-paper/`。
