# 本批验收：固定比较结果进入图、可编辑文稿与离线包

范围：只使用上一批 Anscombe 第 2 组一阶/二阶的两个完整 Run 及已停止的研究活动。基于它们归档的两份指标与 11 行逐点预测，生成一幅有来源绑定的 PNG、用户可编辑的 TeX、固定 PDF 报告和本地成果包。不追加模型训练、科研 Run 或未验证的外部结论；本批文稿由验收夹具撰写，不冒充 Pi 生成。

1. **固定数值到图。** 一个单独批准的 Docker 开发作业明确绑定两个 Run 的 `metrics.json` 和 `predictions.csv` 四件输入，生成 PNG 和图形数据说明。图中 11 个实际点、一阶与二阶留一预测来自同一行；重算的两项留一 MSE 与 Run 指标一致。缺失、错配或篡改输入时不得生成可采纳图形。
2. **可编辑文稿与真实编译。** 文稿修订保留完整 `main.tex` 与上述 PNG 的原产物 ID/摘要，写明固定 R 数据、实际误差、预设阈值、停止决定与“仅限这 11 点”的限制。编译要另行批准固定 XeLaTeX 镜像并产生完整 PDF 和页图；未批准不能提交，退出成功不等于科学结论通过。
3. **固定报告与离线交付。** 报告同时纳入本次文稿结果和已停止的研究活动，准确回到两项 Run、图形作业、可编辑 TeX 与 PDF。成果包解包后，清单所列文件的长度和 SHA-256 全部一致，包含图的固定脚本/四项输入与论文源码；错误项目、失效批准或缺少必要产物不能生成新的有效交付。
4. **重开与历史。** 关闭重开控制对象并刷新工作台后，原两个 Run、比较/Stop、文稿修订、构建、报告及包仍可按原 ID 回查；隔离副本中的上一批描述性 Run、PMC 报告和既有记录不被改写。浏览器与真实 Docker 只验本批关键路径，缺少环境的检查如实标记未验证。

原论文全文未获取，本批只引用其书目信息和 R 官方固定数据；图形来源绑定与数值核验分别记录，不将一个自动等同另一个。前端布局继续暂缓。
