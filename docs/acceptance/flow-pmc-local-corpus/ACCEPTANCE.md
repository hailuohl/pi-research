# 固定 PMC OA 全文进入本地词项语料：本批验收条件

1. 所有者显式选择已保存的 PMC OA `DocumentVersion`，固定其来源版本、原始 XML 与派生文本摘要后启用本地语料；以指定词检索得到可回查的原文片段，显示确切文档身份与“无 PDF 页码”，全程无新增 HTTP、模型或 Docker 调用。
2. 网络取得后不自动入语料；摘要、普通供应商文本、非 PMC/非 OA、缺失许可或来源绑定不一致的文档拒绝加入。旧 PDF 会话授权与普通 Agent 不得借此读取全文；跨项目、关闭/移出来源及来源字节失配均拒绝新检索或缓存回放。
3. 关闭检索或重开工作台后，已保存的检索和证据仍可按原身份回查；现有用户导入文本和已批准 PDF 页语料的行为不回退，不改写既有文档或检索记录。
4. 浏览器完成一次选择全文、保存范围、词项检索、查看片段和返回固定文档的关键路径；不把词项相关性当成科学结论，不声称 PDF 页码。本批不调整前端布局。
