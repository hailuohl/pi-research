## 1. 结论（限本轮数据、两固定模型、唯一固定划分）

**按事前冻结的两条件操作判据，判定为证据不足（insufficient_evidence）：不宣称二次回归满足本轮操作增益判据，也不宣称二次更差。**

- 条件①：ΔRMSE ≥ 0.03（假定操作阈值，quality分）→ 实际 ΔRMSE = +0.00099，不满足；
- 条件②：ΔMSE 自助CI下限 > 0 → 实际 CI = [−0.00456, +0.00775]，跨0，不满足；
- 两条件均不满足 → gain_declared=0。判据的两条件分别定义在不同量上（ΔRMSE与ΔMSE的CI），不可互换或平方换算：ΔMSE = (RMSE_lin − RMSE_quad)·(RMSE_lin + RMSE_quad)，数值上 0.00099×1.44058 ≈ 0.00143，与ΔRMSE是不同的量。
- 辅助符号检验 p=0.000156：多数测试记录二次平方误差更小。该检验的对象是 Pr(d>0)=0.5（方向优势），**不是均值ΔMSE**；按冻结规则，幅度与区间证据不满足判据，结论仍为证据不足。CI跨0表明数据与零效应及小于判据相关量级的正效应均相容，不构成对曲率假设的反驳。

## 4. 各统计量的确切语义与证据关系

- **ΔRMSE点估计**：两固定模型在该271测试组上的RMSE之差，+0.000995分；相对假定阈值0.03约为其1/30。
- **自助CI**：对**固定训练出的两个模型在现有271测试组上的配对损失差 d_i** 做普通非分层组bootstrap——从观测测试组的经验分布有放回抽取配对损失差再取均值得到ΔMSE均值的百分位区间。重采样中各quality层的组数可以变化；它固定已训练模型，不重训、不重新划分原始数据，不保持quality分层计数，也不覆盖原始分层设计的不确定性。其有效性的前提是d_i在记录组间独立同分布——该假设未经验证。区间覆盖的仅是这一固定模型/固定划分条件下的抽样变异性，不覆盖训练随机性、划分选择变异、总体外推与测量变异。本轮未比较其他区间方法，不存在“对方法选择不敏感”的证据，不作此声称。
- **符号检验**：检验Pr(d>0)=0.5。结果（p≈1.6×10⁻⁴）说明二次平方误差占优的记录显著过半，与ΔMSE点估计为正一致；但它不度量幅度，且与CI共享同一未验证独立性假设。三者方向一致偏向二次，幅度与区间证据不满足冻结判据。

**加权敏感性检查的准确语义**：analysis.json中的“全行敏感性”是用**同一对已训练模型、同一组级划分**，把测试侧重复行按原样加权计入指标（313行）。它**不是**用全部行重新训练，也**不能**证明结论对去重选择不敏感；它只表明在该局部重权下判据仍未满足（ΔRMSE=+0.000894，与主分析同向、同量级）。

## 5. 阈值、解释边界与有序响应

- 0.03是**本轮事先设定的假定操作性阈值**（定义在ΔRMSE上），无领域依据支撑其为重要性界值；不据此断言更小的差异“可忽略”或“无操作意义”。本报告只陈述：实测ΔRMSE约为该假定阈值的1/30，且ΔMSE区间与零相容。
- quality是**有序**感官评分；RMSE/MAE/R²把分差按等距数值处理，这是建模选择而非评分量表性质的证明。测试R²（线性0.227、二次0.229）只描述单变量数值方差解释比例，不用于任何机制或因果解释。
- 非因果声明：alcohol–quality关联可能由共同原因（成熟度、品种、工艺等）驱动，本研究不区分。
