# 八项方法的真实 Pi 科研实测

2026-10-17。实测已发现自动触发和科学解释的缺口，不能判定八项方法已能全自动正确使用。原入口首次自然任务读取0/8；补充overview触发表后，新会话使用完全相同提示读取2/8；一次方法覆盖提醒后才读齐8/8。随后代码、自检和报告仍需操作者及独立复核纠正。最终完成真实计算与报告，不把这次有干预的成功改写成无人干预通过。

## 固定任务与验收范围

只走一条流程：公开红酒数据 → Pi读输入并制订方案/写代码 → 核对后固定来源与批准 → Docker正式Run → Pi读回产物写报告 → 来源回查和重开。前端布局暂缓，本批通过真实HTTP入口调用产品和Pi SDK，未做浏览器操作。

1. **真实引擎与输入**：实际Pi SDK/供应商调用，固定公开数据和有限文献候选集，无mock替代。
2. **方法触发与使用**：从原生成功toolResult、resource内容摘要和产品事件核对八项；自然触发、提醒补读、正确使用分别判断。
3. **科研计算与解释**：见测试结果前固定代码/协议，真实容器产物可独立重算，效应、区间、功效和文献边界不虚构。
4. **审批与历史**：未批准Run被拒、准确批准后单次执行、同键回放不重复；旧会话、失败稿、固定来源和重开历史保留。
5. **补丁交付**：仅补强overview方法入口及对应发行/编译文件，独立核对快照、集中回归和干净构建；不混入其他在途改动。

第2条的“自然完整触发/自动正确使用”未通过；第3条只能按“人工核对纠正后通过”验收。模型能力与单个任务相关，本轮结果不能外推为其他模型或更多任务的成功率。

## 实际结果

正式Run：`0961eea6-e135-4a5d-9a68-ca22ee4f6a67`，`succeeded / integrity=complete`，容器执行7.565秒。精确代码、协议、CSV和输入manifest均在执行前固定。Pi生成的完整报告见[final-report.md](final-report.md)；它与系统固定来源报告是两个独立Artifact，正文不会自动并入系统报告。

| 观测量 | 实际值 |
|---|---:|
| 线性RMSE | 0.7207848393 |
| 二次RMSE | 0.7197902926 |
| ΔRMSE（线性−二次） | 0.0009945468 |
| ΔMSE均值 | 0.0014327194 |
| ΔMSE bootstrap 95%区间 | [−0.0045595292, 0.0077511643] |
| 辅助精确符号检验p | 0.0001557004 |
| 冻结操作增益判据 | ΔRMSE≥0.03，且ΔMSE区间下限>0 |

两条件均未满足，判为证据不足。0.03是未经领域验证的操作阈值；辅助符号检验目标为正差概率，不能代替平均损失改善判据。Bootstrap只对固定模型、固定观测测试组的损失差做普通非分层重采样，依赖未验证的iid记录组假设；不覆盖训练、划分、分层设计、测量或总体外推的不确定性。近重复/酒样身份未知，quality有序但被按等距数值建模。

独立Sol/high复核使用NumPy SVD重拟合，核对全部271条预测/误差、系数、训练与测试重权指标，差异≤1e-10；20,000次配对bootstrap与SciPy精确二项符号检验相符。复核不运行Pi生成程序的main，不把实现自检当作独立数值证据。报告修订只复核受影响部分，没有重跑正式Run。
