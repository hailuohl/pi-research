# 固定 PMC OA 证据进入报告与离线包：本批验收条件

1. 所有者选择由本地 PMC 词项检索产生、已接受的精确证据，创建报告并生成离线包；报告固定原文 XML、派生文本、文档版本、许可、引文区间与摘要，包内字节和清单可核对，不声称 PDF 页码或科学结论已获验证。
2. 同一 PMC 产物经普通 `evidence_register` 生成而缺少 `providerText` 绑定、跨项目证据、XML/派生文本/文档身份失配及失效引用，均不得进入新报告或成果包；失败不发布半成品，也不放宽原有审批。
3. 关闭本地语料和重开后，已完成的报告/包及其确切来源仍可回查；旧 PDF 页段报告、普通用户文本报告及先前 PMC 检索历史保持原义和身份，不重跑旧任务。
4. 工作台一次回看 PMC 报告引用、许可和固定文档回跳；仅验功能路径，不调整布局。本批不触发 Pi、Docker、远程发布或新 HTTP。
