# 指定 Pi 会话检索固定 PDF 原页

现在，用户可在已启用的本地原文语料中选定一份原始 PDF 及其完整、已批准的解析版本，为**一个指定主 Pi 会话**准备、批准并激活最多两次新词项检索的授权。授权冻结会话模型、语料版本、文档/解析来源摘要与期限；准备、批准、激活都不启动模型。Pi 只能对授予的页文本检索，返回物理页、精确区间和 Evidence ID，用户可回跳原 PDF 页。该授权不开放整页/原件下载、其他文档、联网文献请求、计算或科学结论。

真实验收使用已有合成二次回归技术文稿的 3 页 PDF：一次固定 Docker 解析 `succeeded / complete`；浏览器完成草案、独立批准、激活后，`zai-coding-cn / glm-5.3` 主会话实际调用本地检索，`MSE` 命中 2 条物理第 2 页片段及两个固定 Evidence ID，并从命中回跳到原页/页图。授权计次为 1/2，未产生新 Run 或文献连接器 HTTP 请求。**本地检索操作**没有额外模型/外部文献请求；本次 Pi 会话本身确有 4 条模型使用记录，不能把模型回复中的“0 次模型调用/未联网”解释为整次会话的网络事实。

撤销后批准记录变为 stale；浏览器刷新仍显示原搜索、页段证据和 1/2 历史计次，owner 可读旧 Evidence。相关回归验证新检索与旧工具回执复用会在授权边界被拒，并覆盖未批准、错会话/文档/模型、超额、过期、语料改变、PDF 通用读取旁路及双控制器竞态。原始 PDF、运行库、会话和日志只留本地；本目录交付[精简机器证据](evidence.json)。

当前只支持指定主协调会话、固定 PDF 解析页和最多两次新的本地词项检索；不等于完整 PaperQA、语义回答或科学核验。非阻断待办：授权卡目前只显示旧检索数量，超过全局最近 10 条后需从 inspect API 回查较早结果；历史数据仍完整。原 PR01–14 余项继续推进，前端布局及 PR14 桌面/团队协作继续暂缓。
