# 固定 PDF 文档语料：原页检索与历史保留

本批新增一条可用流程：用户在文献视图中显式选定 **DocumentVersion + 已批准的完整 ParseResult**，启用后对固定 PDF 页文本做本地词项检索。Wine 原 PDF 的 17 页进入同一冻结语料；查询 `fixed acidity alcohol` 返回 5 条片段，第 2 条是物理第 5 页。命中保存精确 UTF-16 区间、页文本摘要、原 PDF 与解析版本；点击后直接显示原页及页图。此功能不调用模型或外部网络，不生成答案、Claim，也不执行 OCR。

默认关闭；任意页 artifact、跨项目或未获批准的解析结果不能冒充来源。PDF 查询仅限所有者，旧用户文本及其 agent 资源边界保持。关闭后刷新，旧检索和证据仍可读，新检索及旧结果重放被拒；原有 3 个 Run、5 份报告未变。浏览器实走了选择、启用、检索、原页回跳、关闭与刷新。原始 PDF、运行数据库和截图只在本机保存，不纳入 Git。

相关检查通过；全量回归 **759 通过、0 失败、22 跳过**。其后发现并修复回跳只更新状态却未滚动到原页的问题；只重验受影响的页面交互、Web 类型检查与 UI 测试。最终隔离干净构建与当前 450 个产物一致；独立权限/来源复核及滚动窄复核均无阻断。详见[机器证据](evidence.json)，原日志留在 `.validation/document-corpus-flow/`。

后续仍需按原 PR01–14 计划推进其他流程：bioRxiv v2 原 PDF 获取此前受 HTTP 429 限流；PDF 语料的 agent 级文档授权本批未开放。另一次离线备份尝试在现有累积数据上返回 `BACKUP_REFERENCE_INVALID`，未形成新备份，记入后续数据备份排查；原控制服务在无活动作业时以同一目录、端口与令牌加载新代码，现有资料可读。
