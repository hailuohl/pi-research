# 固定文稿、隔离构建与错误回查

本批完成“创建固定文稿→单独批准→隔离编译→定位错误→新修订重建→预览和下载”流程。入口在工作台 **报告与成果**。完整 PR01–14 保留，论文写作、成果包联动及远端发布没有因此完成。

## 实际交付

文稿修订固定入口、引擎、参考文献策略及每个文件的摘要。页面提供三种基础 article 模板、文本编辑、文件和既有产物输入；修改保存为新修订。已知 Run/Sandbox 图形保留产物、源码、清单和批准来源，未知来源如实标记。13 个新增 owner 操作纳入统一 Registry，当前共 **101 个操作**；用户显式配置编译器，每次构建单独批准，不授予 Agent 编译权限。

构建使用固定 Linux/amd64 Docker 镜像，复用共享 CPU/内存/作业预算和持久 worker。运行时不下载依赖，无网络、shell escape、宿主凭据或 Docker socket。可信监管程序在镜像中，TeX 临时目录与结果分开；实际退出码、引用收敛、PDF/PNG 格式和摘要全部通过才发布成功。错误日志和行号保留，失败或不完整结果不显示可用 PDF。

固定环境包括 pdfLaTeX、XeLaTeX、LuaLaTeX、BibTeX/Biber 和中文字体。257 个 Debian 包按版本、大小和 SHA-256 固定，下载共 346,595,108 字节；构建安装约 936 MB。单作业 1 CPU、768 MiB RAM、64 PID，监管总时限 120 秒、最多 6 轮 TeX、100 页、32 MiB PDF、128 MiB 总输出。依赖和构建方法见[编译器说明](../../../scripts/document-build/README.md)。

## 明确保留的限制

- LuaLaTeX 加载大型 Noto CJK 字体在 768 MiB 预算下被 SIGKILL，准确标为失败；本批中文实物用 XeLaTeX，不宣称 Lua 中文通过。
- 输出监控和容器可写目录限制不是宿主硬磁盘配额。Lua `io.output` 可写容器可写挂载，但伪造结果会被监管程序在子进程退出后覆盖并按实际错误判失败。
- 基础模板不是期刊模板全集；编译成功不等于科学结论、全部排版或任意 TeX 包兼容性通过。ASCII 相对文件名、文件/字体/时间上限按配置执行，不自动装包。
- 冻结的内置 paper 技能仍是原发布包文本。当前能力由应用和运行时目录表示；更新内置文本前需补齐旧 bundle 的历史迁移，避免破坏原生会话固定绑定。声明 latex 后端的受管技能已接入实际编译器预检。
- 下一批将文稿 PDF、固定源文件和图形/数值来源接入报告与离线成果包，并补足回跳。完整写作工作流、diagram 执行器、PR07 剩余项、远端/GPU 与 PR14 分发仍保留。
