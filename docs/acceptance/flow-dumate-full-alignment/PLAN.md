# 纯 DuMate 完整能力对齐范围

基线：`e2889fe0bab922d68d6cfd7d0c03b3d3dcdda819`。本计划在实现前固定范围；当前实际状态见PROGRESS.md及evidence.json。用户要求全部可对齐实现完成后，再集中测试。

本批交付一条流程：明确问题与计划 → 多源文献和证据 → 获准的新分析/图形 → 同源复杂稿件 → 限定修订与交付。实际已有研究数据不重新分析，旧稿、旧包、旧 helper、1.0.2 排版及收据不覆盖。

## 固定验收条件

1. 安装包可独立在纯 DuMate 使用，所有输入显式选定，来源和计算真实，不依赖 Pi/研舟服务、数据库或外部模型执行器。
2. 计划、完整图形方法、适用统计、多源读取、PDF 原页、原生可编辑公式/表格/脚注、实际模板与题名/context 修订可接成稿件流程；不只生成孤立文件。
3. 缺失、坏输入、越界、跨任务、摘要变化、依赖/网络/字体失败和警告准确失败或部分完成；生成、机械核查、科学核对、看图和独立审阅分别标记。
4. 新 ID 另存，重开验证原字节/代码摘要；保留历史、失败与未决锁。限定修订只改显式获准内容，原来源范围和身份保持。
5. 实现完成后集中回归、隔离新示例、安装/原生关键路径及独立复核；未运行或平台不可用不能写成通过。

## 平台门槛与不移植范围

DuMate 独立代理此前只回显提示，实际图像送达也有平台缺口；不能用脚本、角色扮演或外部模型冒充原生能力。文件摘要/历史不冒充服务端事务、CAS、撤权传播、常驻调度、Docker/SSH/GPU Run。上传任意 cls/sty 的无隔离编译不作为可安全实现项；保留依赖、提供安全映射并如实标记不支持的规则。
