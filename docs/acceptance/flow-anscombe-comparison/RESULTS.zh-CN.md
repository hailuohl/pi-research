# 第 2 组固定数据：实测比较后停止

新增可用能力：沿上一批的 [R 官方 Anscombe 固定数据](../flow-anscombe-baseline/anscombe.R)，为第 2 组建立一阶对照和仅改 `degree` 的二阶候选。两个模型使用同一程序、容器契约和 11 次留一评估，各自单独批准正式 Run；研究活动固定了对照、主指标、10% 阈值和一次候选上限，再经单独批准 Stop。浏览器刷新后仍可回查两项实测观测、方案和停止理由。

| 固定模型 | 11 次留一均方误差 | 训练集均方误差 | 逐点预测 |
|---|---:|---:|---|
| 一阶 | 2.204181036321706 | 1.2523900826446281 | [11 行](predictions-linear.csv) |
| 二阶 | 0.0000031116060756864716 | 0.000002034329307056081 | [11 行](predictions-quadratic.csv) |

二阶/一阶留一误差比为 `0.00000141168`，达到事先固定的 `≤0.9` 阈值；这只说明**这 11 个已知点上的留一评估**。模型阶数是看过同一数据后提出的，没有独立外部测试集，不据此断言普遍预测优势或原论文的其他结论。原论文与 [R 数据集说明](https://search.r-project.org/R/refmans/datasets/html/anscombe.html)的来源边界沿上一批记录。新比较程序见 [compare.py](fixture/compare.py)，运行快照中的[一阶配置](config-linear.json)与[二阶配置](config-quadratic.json)仅改变 `degree`；原始数据与解析器沿用上一批，完整身份和摘要见 [机器证据](evidence.json)。

越界与历史：未批准的一阶 Run、Refill 决定和二阶 Run 均被拒；Stop 后新决定被拒。两项 Run 都是 succeeded/complete，11 行预测可从归档值重算主指标。重开控制对象后活动仍 stopped，上一批描述性 Run、旧 PMC 报告和隔离副本的 69 条既有非设置记录保持原值。本批没有 Pi 模型调用。

剩余工作：下一条流程是把固定结果接入图表、可编辑论文和成果包。活动 UI 仍把已执行候选的实现状态显示为 `prepared`，比较状态同时显示停止理由；本批表格、真实 Run 与 Stop 状态正确，文案整理留后续。SSH 仍无主机，前端布局继续暂缓；原 PR01–14 其他范围保留。

验证：公开数据夹具分别跑通一阶/二阶并拒绝错误摘要；相关研究方案、决定与活动检查 39 项通过，其中缺失指标 Run 被标为不完整观测；正式 Docker Run 两次、浏览器关键路径一次。独立只读复核用另一种数值解法重建了 11 折预测，无阻断；批准和历史保留由主代理的本地运行记录核对。产品源码没有变更，未重复全量回归和干净构建。完整日志与数据库留在本地 `.validation/anscombe-comparison/`。
