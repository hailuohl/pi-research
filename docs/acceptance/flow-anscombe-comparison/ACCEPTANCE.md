# 本批验收：真实固定数据上的一轮模型比较与停止

范围：沿上一批 R 官方 Anscombe 数据的固定 SHA-256，只研究第 2 组的 11 个 `(x,y)`。以相同留一法（LOOCV）比较一次一阶与一次二阶最小二乘拟合，使用已有正式 Run、研究活动、方案/决定和批准机制；不自动扩展到其他组或宣称外部预测能力。

1. **同源同协议。** 两个正式 Run 的 `anscombe.R` 和比较程序字节摘要相同，只允许配置 `degree: 1→2` 一项变化；每次留一法恰好用其余 10 点拟合、预测被留出的 1 点，固定 `loocv_mse` 为主指标（越低越好），保存 11 条逐点预测与原始指标。
2. **实际比较与决定。** 分别批准并执行一阶基线与一项有界二阶候选，在同一研究活动的已批准方案中记录对照、变化因素、评估协议和停止规则。比较只读取实际归档的完整 Run；若二阶 `loocv_mse` 比一阶低至少 10%，记录“此 11 点留一评估有改善”，否则记录未达阈值。两种结果都以单独批准的 Stop 结束，不追加候选或模型调用。
3. **越界或失败。** 未批准的决定不能生成候选，未批准的正式 Run 不能提交；与固定来源或契约不符的候选不能作为同协议结果，停止后不能再新增运行方案。失败/缺指标的 Run 不可当作有效比较结果。
4. **重开与历史。** 关闭重开控制对象后，两个 Run、11 条预测、固定方案、比较与 Stop 仍可按原 ID 回查；上一批描述性 Anscombe Run、旧 PMC 报告及隔离副本的既有记录原值保留。浏览器仅核对本批的比较/停止与刷新关键路径一次。

程序由验收夹具提供，真实 Pi 生成不在本批范围。Docker、浏览器或其他环境若缺失，按用户要求明确记为未验证，不冒充通过。
