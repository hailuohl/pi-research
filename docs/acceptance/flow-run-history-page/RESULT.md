# Run 历史按游标分页

所有者现在可调用后端 `run_list`，按项目和稳定游标取最多 100 条 Run 摘要，再用原 `run_inspect` 读取选中运行的完整清单与产物。摘要只含身份、状态、时间、清单摘要及已有指标，不带工作目录、执行句柄或 SSH 私有配置。原 `/projects/:id` 响应和前端未改，后续前端可按需改用此入口。

本机 HTTP 验收使用两项真实 Anscombe 比较 Run：限制每页 1 条，游标 `78 → 101`，第二页明确结束；按第二项 ID 回查原清单摘要一致。跨项目结果不混入，非法游标和超限页被拒。关闭重开后原游标仍得到同一 ID；两条 Run 记录、10 项产物摘要保持，未新增模型、连接器请求或 Run。相关单测还覆盖插入新 Run 和更新旧状态后的续页、项目隔离及现有索引使用。

本批仅补 PR07 的这一条后端历史读取流程，未宣称旧项目总览已分页或完整性能迁移。简短机器证据见 [evidence.json](evidence.json)，原始回归日志留在本地 `.validation`。前端布局继续暂缓。
