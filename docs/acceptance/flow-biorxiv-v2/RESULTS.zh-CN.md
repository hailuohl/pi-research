# bioRxiv v2 原 PDF：来源限流，未形成文档版本

本批**没有取得可用的 bioRxiv 原 PDF**。针对既有实网元数据中的 DOI `10.1101/322859`，新项目显式启用 bioRxiv，并只请求固定 **v2**。首个持久文献任务向官方 PDF 地址发出一次计量请求，收到 **HTTP 429** 与 `Retry-After: 53` 秒。等待超过该时限后，用户入口“显式重试”创建一条关联旧任务的新记录；第二次仍为 **HTTP 429**。两次失败均原样保留，没有生成 DocumentVersion、解析页、证据页段或科学结论；不把元数据/摘要当成原 PDF。

缺少版本和来源禁用均在网络前被拒；跨项目读取旧 Wine 文档返回 `SCOPE_DENIED`。浏览器刷新后可见两条 v2 失败任务、准确限流状态及“尚无固定 DocumentVersion”；旧 Wine 项目的正式 Run、文稿构建和报告身份保持不变。当前障碍是提供商对本机请求限流，不能由测试夹具或换用用户上传文件代替本批成功路径。后续需在来源允许访问时再做**新的显式**获取；本批不继续试探该站点，转向不依赖它的 PR10 文档语料缺口。

本批没有产品代码改动，也没有启动 Pi、Docker 解析或重复全量回归/干净构建。独立只读复核确认 429 分类、任务血缘及旧项目记录保留，未把失败解释成 PDF 解析结果。确切任务、两次 HTTP 状态、刷新与保留边界见[机器证据](evidence.json)；原始请求记录留在本机 `.validation/biorxiv-pdf-flow/`。
