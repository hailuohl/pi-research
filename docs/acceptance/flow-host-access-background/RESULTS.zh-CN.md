# 本机完全访问：后台自动启用

2026-10-08。本批只修改启用完全访问这一条流程：执行中点击并确认后立即接受请求，当前轮次保留原权限；旧 Worker、执行准入和受管宿主命令退出后，后台自动启用，再继续普通排队消息。无需等整条队列清空或再次点击，可在生效前取消。没有修改前端布局或增加依赖。

验收条件及结果：

1. running/queued 会话可提交明确启用，不再返回 SESSION_BUSY；queued-only 且没有在途执行时立即启用。
2. 当前任务正常结束；仍匹配原权限的普通排队消息自动衔接 fullAccess，未投递 steer 留在队列，原内容和历史保留，宿主命令不重放。
3. 保留范围确认、未知效果确认、版本校验、固定范围限制；失效输入、子任务和自动唤醒不会继承完全访问。
4. 取消待启用请求不使当前权限或审批失效；生效后撤销阻止新宿主命令；服务重开不恢复 pending/fullAccess，历史保留。
