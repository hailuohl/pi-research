# 静态 PNG 技能包导入与固定回查：本批验收条件

1. 所有者在工作台显式导入只含 `SKILL.md` 与 `assets/figure.png` 的受限 ZIP；产生待审修订，经独立的审阅批准和显式启用后，资源按原字节及 SHA-256 回查，下载入口可用。导入/审阅/启用均不启动 Pi、脚本或计算。
2. 不安全 ZIP 路径、非规范 PNG 或未审修订不能进入新技能 Bundle；Agent 文本技能读取不能把二进制 PNG 当文本或执行资源。失败不发布可用修订。
3. 撤销后新绑定不能使用该修订，已固定修订与审阅历史仍可重开回查；先前项目文档、报告与失败任务身份不变，不重跑任何旧作业。
4. 浏览器只验一次导入、审阅、资源回看与撤销关键路径。若当前浏览器控制不支持可靠的原生文件选择或本机下载落盘，保留服务端字节/摘要验证并如实标记该 UI 环节未验，不反复试错。
