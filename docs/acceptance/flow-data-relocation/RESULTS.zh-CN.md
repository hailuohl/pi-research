# 保留冻结身份的异址迁移

已实现离线 A→B→C 迁移：新文件使用 `pi-data:/` 引用，旧绝对引用通过所属数据库的位置记录解析到当前目录。旧业务记录、批准与清单摘要、原生 Pi 历史不重写；受管 Git 工作副本的位置指针单独迁移。未知根、损坏映射、越界引用与链接明确拒绝，旧目录存在时也不回退读取。

```powershell
node dist/apps/cli/index.js backup create --data "D:\PiData" --out "D:\PiBackups\saved" --offline
node dist/apps/cli/index.js backup restore --data "D:\PiDataNew" --from "D:\PiBackups\saved" --offline --relocate
```

先停止源控制器与其他 CLI，目标必须不存在；迁移后只使用新副本，原件保持离线。不同数据库副本不共享提交额度。备份保留私有研究正文和日志，认证文件排除；当前只支持同一平台。

实际旧数据完成两次 CLI 迁移：A 的 53 条记录、48 个非数据库文件保持不变；B 通过现有用户接口新建私有文件与产物，C 重开保留全部 56 条记录和 7 个可读产物。98,774 字节的原生 Pi 文件摘要及原生 ID 未变，安装的 SDK 离线打开时使用 C 的运行目录。浏览器回查 14 条旧消息、2 条新本地消息及新旧产物，刷新保留列表。产物预览选择在刷新后重置，记为后续非阻断项；未评估布局。
