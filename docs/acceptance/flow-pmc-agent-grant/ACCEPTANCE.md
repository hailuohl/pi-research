# 指定主会话有限检索 PMC OA 全文：本批验收条件

1. 所有者在已启用的固定语料中选定一份 PMC OA `DocumentVersion` 和一个主协调会话，准备范围、最多新检索次数及截止时间；单独批准并激活后，该会话只可对选定文档做有界本地词项检索，返回绑定 XML/文本/版本的片段证据，不发生新 HTTP、模型或计算调用。
2. 未批准、未激活、越过文档范围、超额、过期、撤销、语料移除或配置变更均阻止新的检索及检索回执重放；已返回片段在授权仍有效时可回读。`artifact_read`、普通 `evidence_register` 和非本次结果的 `evidence_read` 不得泄露 PMC 原件或全文。Task/Wakeup 与跨项目身份不能借主会话授权读取。
3. 授权计次、精确检索结果和审阅记录在刷新/重开后保持；撤销阻止新效果，但已完成的历史命中和原文证据仍可按原身份由所有者回查。既有 PDF-only 授权与用户本地检索行为不回退。
4. 浏览器只验所有者准备、批准、激活、撤销及历史回查的关键路径；若当前环境没有可用的真实 Pi 会话，Agent 检索用受控现有测试会话验证并如实标明 Pi 实测跳过，不为此重启模型或作业。本批不调整布局。
