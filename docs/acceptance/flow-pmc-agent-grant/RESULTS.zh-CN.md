# 指定主会话有限检索 PMC OA 全文：本批结果

新增可用能力：所有者可把**一份固定 PMC OA 文档**授予指定主协调会话，沿用现有草案、单独批准、激活、计次及撤销流程。隔离副本的 1 次额度实际返回 5 个绑定 XML/文本/版本的原文片段；额度用尽后检索回执不能重放，已返回证据在撤销前仍可回读。浏览器完成准备、批准、激活、用量刷新、撤销和历史回查。

剩余工作：本批用受控会话身份验证 Agent 工具权限，没有启动真实 Pi 或模型；真实 Pi 交互按可用运行环境后续验。授权只覆盖单份 PMC 文档，不允许 PDF/PMC 混选、全文下载、普通证据登记或科学结论自动采纳。旧 PDF-only 授权的字段摘要和耗尽后精确重放规则保持原义。

边界：未批准/未激活、越界、额外来源、Task/Wakeup、完整 XML/文本读取及非返回证据均拒绝；撤销后旧检索和证据回执也不能由该 Agent 重放。所有者重开仍能回查原片段；旧 55 条非语料设置记录摘要不变，新增 HTTP、模型、计算调用均为 0。独立复核无本批阻断。

验证：干净构建通过；集中回归 837 通过、0 失败、22 跳过；后端相关及界面相关检查通过。机器摘要见 [evidence.json](evidence.json)。原始日志和验收数据库留在本地 `.validation/pmc-agent-grant/`，不提交私有研究原文。
