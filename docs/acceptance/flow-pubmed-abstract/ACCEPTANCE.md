# PubMed 结果到固定摘要：本批验收条件

1. 复用既有真实 PubMed 第一页结果中的 PMID `29860986`；所有者显式启用来源并提交一次 `provider-text` 获取，持久任务成功，形成绑定 PMID、原响应摘要和获取时间的 DocumentVersion。若来源只给摘要，必须标为 `abstract`，不显示原 PDF 页或全文保证。
2. 关闭来源后新获取在网络前拒绝；跨项目读取固定文档也被拒，不得借已有检索结果越过项目或来源开关。
3. 浏览器能从固定任务打开该摘要并在刷新后重开；既有 PubMed 两页检索和 bioRxiv 限流失败记录保持可回查，旧结果不被重写。
4. 本批不调用 Pi 或 Docker，不形成科学 Claim；若官方 EFetch 不可用，保留真实失败与请求计数，不以旧检索摘要冒充新取得的 DocumentVersion。
