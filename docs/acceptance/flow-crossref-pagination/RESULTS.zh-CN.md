# Crossref 显式下一页

现在可以在文献检索页用已启用的 Crossref 提交单来源默认关键词检索，查看固定第一页，再显式取得下一页。两页各有独立的持久任务、结果和 HTTP 计次；客户端继续时只提交前页结果 ID，查询、过滤条件、上限和游标由服务端冻结。刷新后仍可按页回查。关闭来源、跨项目引用、伪造游标、额度不足或游标过期会在外发前拒绝；失败不会伪装成空结果。同一分页任务重复重试也不会产生多个外发任务。

真实浏览器与 Crossref 验收：`wine quality` 两页各返回 8 条元数据，第二页有 8 个第一页没有的 DOI，总计 2 次 HTTP。关闭 Crossref 后新页请求返回 `CONNECTOR_SETTINGS_CHANGED`，HTTP 仍为 2；刷新后两页任务和结果可读。页面只标注元数据，未声称取得原文或完成科学核验。截图与原日志留在本地 `.validation/crossref-pagination/`，本目录只保存[精简机器证据](evidence.json)。

当前范围仅覆盖 owner 的 Crossref 单来源、关键词和默认排序；本地游标期限为 4 分钟，并非 Crossref 提供的保证。其他来源分页、RunGrant、DiscoveryGrant 与原 PR01–14 剩余流程继续按计划分批处理；前端布局仍暂缓。每页上限目前固定为 8，界面尚未直接说明，列入后续待办。

修复后相关检查 29/29；集中全量 793 项中 771 通过、22 跳过、0 失败；隔离干净安装、构建和类型检查通过，450 个构建文件一致。独立权限与恢复复核指出的 2 项阻断均已修复，定向复核无剩余阻断。本批没有重跑 Pi 或 Docker。
