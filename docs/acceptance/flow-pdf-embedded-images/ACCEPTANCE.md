# 固定 PDF 嵌入图像定位：本批验收条件

1. 所有者对已有原 PDF 明确准备、批准并提交固定解析；两页样例的物理第 2 页自动产生至少一个嵌入栅格对象候选，页内位置可回看并与同一固定页图对应。只称“嵌入图像候选”，不判定科学 Figure、图注或数值。
2. 无嵌入图像对象的三页样例返回空候选；越界、非有限或与文件摘要不符的解析输出不能发布成功结果。图结构质量仍标为 unknown。
3. 仅沿用原解析的所有者、项目及审批边界；跨项目或未批准的解析不能借候选读取原件或生成可用结果。
4. 刷新后可从固定解析结果重开相同页和候选；已有 v1 解析结果及其页证据仍可读取，进行中的任务不因本批重启。
