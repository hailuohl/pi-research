# 个人模板库：设置上传、查看与跨项目选用

2026-10-07。基线 `12313098779b1d0cff25935421ab73c7a4c09fbf`。

用户本次要求同时完善模板库、创建项目时可选 GitHub 上传及本地/Docker/SSH GPU。按项目规则分批交付；本批只完成模板流程。前端仅增加用户明确要求的设置入口和选用接线，不重做布局，不改原有五个在途文件。

## 验收条件

1. 设置页在有项目或无项目时均可列出内置及个人模板，上传单个 `.tex` 或包含配套文件的 ZIP，查看模板文件列表及可读正文；上传后自动更新，无多余刷新/启用按钮。
2. 另一个项目可选用已上传模板。创建稿件时在目标项目固定实际文件内容和编译设置，同名新上传不改变旧模板与已有稿件；关闭重开及异址备份恢复后保持，不绑定开发机路径或账户。
3. 交互主协调 Agent 可生成模板并通过明确工具保存，遵守当前会话动作策略；模板读取不授予其他项目资料读取权限，后台 Task 不获得全局模板写入权限。已有 Agent 生成稿件流程继续可用。
4. 非法路径、符号链接、超限文件和无效 ZIP 被拒绝，重复请求不重复导入；导入和查看不执行模板内容，项目内证据与历史绑定不被改写。

只提供上传、查看和选用，不扩展为模板市场、在线下载、团队共享、删除或编辑管理系统。复用现有存储、ZIP读取、稿件冻结和权限机制，不新增依赖。源码须可移植到 Windows、macOS、Linux；各平台实测状态分别记录，不以本机通过冒称所有目标已验。原日志存于 `.validation/product-options-20261007/`。
