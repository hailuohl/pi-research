# 研舟π纯DuMate科研助手应用方案

1.0.1 应用方案 · 2026年10月14日

研舟π科研助手面向需要整理文献、分析小型数据并交付论文初稿的学生和科研人员。用户在DuMate中提出研究问题，选择论文和CSV，组合技能将选定材料组织为可回查的证据、真实统计、科研图形及可编辑文稿。

本方案对应1.0.1技能包。组合技能已在DuMate实际完成文献检索、证据整理、六行合成数据分析、科研绘图及MD/DOCX/PDF文稿交付。已完成产物与对应来源、数值和图形的检查，保留版本与失败记录。修正发布目录P2的12份科研文件和4份安装演示文件均已在桌面端导出，并生成所选两条答复的实际分享链接。按用户要求跳过分享访问测试；本材料尚未代提交比赛。

## 作品简介

研舟π科研助手面向学生与科研人员，把文献研究、证据整理、CSV描述统计、科研绘图和论文交付组织为一条DuMate任务。AI负责阅读判断和写作，脚本负责真实计算、原话定位及版本校验，输出可编辑文稿与PDF。作品重视来源、数值和图文的一致性，并明确材料缺口与研究限制。

## 用户需求

文献阅读、数据计算、绘图和写作常在不同工具间进行。整理结果时，来源页码容易丢失，图形与正文可能使用不同数据版本，模板中的示例引用也可能被误留在稿件中。用户需要把研究问题、选定材料与最终成果对应起来，并在修订时保留原稿和原始输入。

首版优先处理有文字层的PDF、UTF-8文本与CSV。没有数据时可以起草文献型稿件；存在数据时根据明确的列、单位及缺失规则进行描述统计。材料不足的部分保留为待补充内容。

## 开发平台与AI作用

作品采用DuMate和一个可安装的组合Skill。Skill包含五份按需方法参考、一个运行脚本和科研绘图资源，配合用户选定工作区使用。运行依赖为普通Python功能库，无需研舟π后端、Pi或研究数据库。

AI负责理解研究问题、设计检索词、筛选文献、阅读证据上下文、解释结果和起草正文。确定性脚本保存检索记录，验证摘录与定位，执行CSV计算及绘图，并根据同一正文和图形生成MD、DOCX及PDF。AI阅读判断和脚本校验共同支持交付，文件生成成功本身不代表科学结论成立。

## 五项核心功能

| 功能 | 首版实际实现 |
|---|---|
| 文献研究 | Crossref真实元数据查询、DOI去重、候选表及选定来源记录；全文另行取得和阅读 |
| 证据整理 | PDF文字层和固定文本解析，物理页或段落锚点，原话核对，证据与主张映射 |
| 数据分析 | CSV输入与缺失校验，分组样本数、均值、中位数、范围及样本标准差，保留清洗记录 |
| 科研绘图 | 按已计算结果生成分组均值柱图，导出PNG、SVG和PDF，保存轴单位、样本数及来源 |
| 论文交付 | 仅引用当前稿选定且实际使用的来源，替换真实结果数值，交付MD、DOCX、同源PDF及成果清单 |

首版使用简单学术结构。扫描件OCR、其它图种、复杂统计模型、期刊模板与复杂公式排版按具体研究需求另行验证。无统计检验的结果保持描述性解释。

## 用户操作与交互

1. 在DuMate导入`yan-zhou-pi`技能包，查看平台给出的权限说明，准备可用Python及所需功能库。
2. 在新任务中说明研究问题、期望成果和语言，选择独立工作区及本次使用的论文、CSV。需要分析时说明列名、单位和缺失处理要求。
3. 让科研助手完成检索、原文阅读、证据整理、分析、绘图和起草。已有输入可直接开展；影响研究选择的关键缺口再向用户澄清。
4. 查看实际图形与PDF，核对来源、主张范围、样本数、单位、统计定义和正文数值。平台模型不具备图像输入时，视觉检查由实际查看材料的人或其它具备能力的验证者完成，并记录检查范围。
5. 下载可编辑稿、PDF、图形和成果清单。修改材料或正文时新建版本；重开任务先核对既有文件，再复用可以确认的步骤。

可使用以下指令开始任务：

> 请使用研舟π科研助手，围绕我指定的研究问题阅读选定论文，整理带原页定位的证据；分析选定CSV，按说明的列、单位和缺失规则计算描述统计，生成对应图形，并交付中文可编辑论文初稿和PDF。只使用本任务选定且有关的来源，实际查看图形及PDF，准确列出未完成检查。

## 材料与结果一致性

每份输入、解析文本、统计结果、图形和稿件保留摘要及任务版本。校验原件保持独立，外发时使用普通文件副本，并分别记录真实来源和平台附件的实际摘要。写作上下文明确选定来源、证据、结果和图形；未选定引用、未知数值标记和过期摘要会被拒绝。正文只把方法文献用于其支持的内容，不把图形设计建议解释为数据的实验结论。

本包脚本对文件路径和任务身份进行校验，拒绝跨任务目录别名与复制来的异任务记录。既有输入、旧稿和失败记录保持；未知运行状态保留pending与锁，阻止盲目写入或复用。脚本校验的范围与DuMate平台权限分别说明。

## 验证样例与当前证据

实际DuMate任务使用一篇有关数值与图形表达的公开方法文章，以及六行明确标注的合成数据。十条真实检索候选按DOI去重，只有指定文章的全文用于本稿，另外九条的排除说明仅依据元数据，不声称读过其全文。三条证据保留物理页定位，三个修订主张区分原文条件与本稿展示选择。实际计算得到A、B两组均值2和4，各组三个值，样本标准差均为1；正文、图形和引用对应同一版本。成果包含真实MD、DOCX、两页PDF和图形，已核对正文、原文支持范围、数值、PNG及PDF全部页面。样例用于软件验证。

组合技能相关14项测试中12通过，2项因原生符号链接权限跳过；真实Windows junction越界另行通过独立检查。独立工程复核已确认任务隔离及中断处理修复。DOCX可编辑内容与结构已检查，DuMate原生预览观察到三页，未作独立DOCX页面渲染认证；简版PDF的英文间距不均属于当前排版限制。

实际DuMate执行流程、六张真实任务页截图及两张桌面端分享操作截图已经保留。原始稿件、选定材料与历史记录保持；校验后的MD/DOCX/PDF和图像来自同一正文、分析结果与图形。P1全部12份附件已从平台实际下载并与本地文件逐字节核对一致。P1的来源清单缺陷由Codex在新P2中修复并通过独立复核，随后DuMate实际核对并导出P2，P1保持。平台给DOCX、PDF和PNG添加元数据或重封装，三个字节摘要变化；独立核对正文、图像及PDF页面内容等价，124份旧文件保持。另存C1记录真实处理后摘要，不改旧清单。P2云端PDF及发布清单两份已实际下载核对，其余十份云端附件未逐项核对。

最终链接已在桌面端生成：[研舟π科研助手](https://www.dumate.cn/s/d9oLSggG)。只分享最新成果和安装说明共16份附件，不包括原件PDF和旧对话。分享页访问、下载及安装复用测试按用户要求跳过。实际1.0.1更新安装和11份安装文件摘要已核对，独立干净安装及缺输入/复用的原始命令返回取证仍有缺口。模型视觉能力不足的检查由实际查看者完成，不写成DuMate自行看过图片或科学同行评议。多智能体派发入口已出现，但两项微型任务及各一次续接没有得到有效答案，维持单入口组合Skill，不宣称多智能体研究已完成。

## 应用前景与推广方式

首版适合课程科研训练、小型数据分析、文献与结果表达练习，以及论文初稿整理。可复用Skill使用户围绕自己的问题和材料开展任务，并保留修订历史。后续推广优先结合课程和研究方法教学，观察实际任务的完成情况，再按需求补充数据格式、图种和模板。

潜在商业方式包括科研方法培训、团队模板配置与部署支持。收费服务、机构集成和规模化使用尚未开展，不据此宣称已有用户或收益。
