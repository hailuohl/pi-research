# 查找旧会话与分页回查消息

工作台现在可按标题/标识和角色分页查找会话，旧会话即使不在最近列表中也能通过服务端精确验证打开。消息默认每页10条，预览每条最多4,000字符、列表最多256 KiB；可向前/向后翻页，刷新保留位置，显式返回最新页后才发送。长消息正文按最多64 KiB的UTF-8窗口读取，生成时已截断与页面预览截断分别标记。

真实浏览器回查原Pi会话：最新10条和最早3条逐条匹配原内容，刷新保留旧页，无匹配搜索仍保留当前会话。152,127字节的明确测试通知验证了连续原文窗口及390px键盘返回；该通知不是模型输出。未新增Pi或Docker调用，707条旧记录中的业务记录和18份原生会话文件保持不变。

独立复核关闭了切会话残留游标、以最近列表误拒旧链接两项问题。真实历史读取首次还暴露空文本BLOB为null的兼容问题；已修复并保留首次失败，同时兼容现有Host保存的长诊断。仅复测受影响部分，未重跑整套流程。原始日志留原处，只交付[一份机器证据](evidence.json)。

测试数据规模为5,001会话/20,000消息：20次目录＋消息页读取，p50约0.921ms、p95约1.133ms，查询计划使用索引、无临时排序。此数值不是整站吞吐或模型性能，数据库锁等待未测。目录重命名/状态需重新查询、聊天页既有窄屏溢出、其他实体分页和完整DTO继续留后续。

集中回归754项：首次731通过、1项空消息失败、22跳过；修复后相关13项及长诊断契约1项通过，无未解决失败。438文件干净构建一致，独立复核无剩余阻断。
