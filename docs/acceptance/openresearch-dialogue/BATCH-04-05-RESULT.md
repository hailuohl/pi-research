# 第4–5批：原对话文稿、编译、审查与成果交付

同一研究会话可从已确认计划和获准的真实 Run 素材生成固定稿件，准备编译、读取诊断并修订；用户在原对话批准固定编译、独立审查及成果导出。仅出现相关任务时显示文稿卡，不新增手工研究入口。

## 实现与边界

- 固定稿件保存可信 root、前一修订、ResearchBrief 引用及证据子集；新修订保留旧稿，旧无会话的 USER 稿件和原清单摘要保持兼容。
- 交互协调 Agent 的新工具检查当前角色、有效租约、同会话目标和嵌套素材。编译 submit/cancel/configure、团队批准启动、报告生成和导出仍由 USER 执行。合法协调会话分支可用。
- 两个 root 可各自使用相同幂等键，不能共享结果或读取对方稿件；回放重新验证身份、固定来源和素材权限。
- Agent 审查外部输入仅限获准同 root 的官方 Run 证据，宿主固定补齐稿件的 Run 指标。受保护 PDF/PMC 引用作为文稿依赖保留，不加入审查 Task 或重新包装原文；审查范围明确记录。
- 对话可查看固定源码、真实诊断、PDF、精确版本审查和归档下载。报告关联从真实 `bindings.publications` 只读投影，重开能找回成果回执。当前列表只显示最近30个构建，较旧记录仍保留。
