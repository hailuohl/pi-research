# OpenResearch 对话研究流程改造

目标：在同一项目和主会话中推进用户的完整研究任务，按 OpenResearch 的实际环节对应；复用现有服务与固定来源，不建立平行的通用流程引擎。前端维持对话、实验树与按需预览的布局。

## 对应与批次

| 环节 | OpenResearch 对应能力 | 本项目交付方向 | 批次 |
| --- | --- | --- | --- |
| 项目、模型、数据与算力 | create / instances / compute | 当前项目、模型、数据、环境与额度检查 | 已有基础，贯穿各批 |
| 明确问题 | ChatPanel 起始研究引导 | 当前主会话的研究问题、范围、待澄清事项 | 1 |
| 检索与阅读 | lit-review / paper | 仅启用来源，区分元数据、摘要和实际全文 | 已有工具，1接计划 |
| 整理证据 | evidence | 真实、获准的证据引用和失效检查 | 已有基础，1接计划 |
| 空白、假设与研究计划 | experiment-tree / 工作树资料 | 问题、假设、证据、成功标准、步骤的修订与确认 | 1 |
| 基线代码与测试 | create / git | 私有源码、受控测试、真实诊断与固定整合 | 2 |
| 代码独立审查 | agent-delegation / feedback | 现有测试、独立审查、整合与父实验衔接 | 2 |
| 实验树与分支 | experiment-tree / create-experiment | 同轮候选与胜出节点后的下一轮 | 2 |
| 正式运行 | exp run / wait / logs | 固定 RunIntent、对话确认、真实执行与回查 | 已有对话基础，2贯通 |
| 结果分析与选优 | experiment-tree / evidence | 固定指标、实际观测、方案比较和决定 | 3 |
| 修复、迭代与停止 | experiment-tree | 限次修复、后续轮次、停止原因与恢复 | 3 |
| 图表 | figures | 固定真实数据到绘图产物与文稿引用 | 3 |
| 文稿与引用 | paper | 从固定证据和结果生成可修订文稿 | 4 |
| 编译与修正文稿 | paper / 本地 LaTeX 编译 | 固定编译、真实诊断、PDF与修订 | 4 |
| 论文审查 | feedback / evidence | 精确文稿版本、独立意见与修改记录 | 4 |

| 历史与恢复 | native chats / Git / 文件 | 保留历史，重开回查当前来源有效性与任务状态 | 每批验收，5贯通 |

## 每批质量门槛

每批只交付一条可走通的流程，先确定3–5条验收条件，覆盖成功、失败或越界、重开和历史保留。开发阶段运行相关检查；集成后集中一次全量回归、干净构建和独立复核，必要修复只重验受影响部分。真实模型、Docker和浏览器仅验证该批关键路径。

## 第1批：研究问题、证据与计划

1. 粗略想法保存为待澄清修订；ready计划须有成功标准、步骤且澄清问题为空。
2. 证据真实、同项目、当前有效并对调用身份授权；假设只能引用已列证据，计划不是实测结论。
3. expectedRevisionId与当前会话指针在事务内比较；新建固定内容修订、保留旧修订，冲突不产生部分写入。
4. 仅本交互式主协调会话可准备或读取；用户确认最新ready版本，不授予计算、代码整合或发布权限。合法会话分支拥有独立计划。
5. 重开仍可回查；失效来源保留历史，Agent回查及写操作重放都不能返回失效或无权读取的派生内容。

后续批次按上表顺序开展；完成情况以各批RESULT及机器证据为准，不能把本表的改造目标视为已实现。
