# 本批验收：分析子任务提交一项冻结正式 Run

范围：所有者为尚未派发的一项 `analyst` Task 选择已准备、未提交且原精确批准待处理的 RunIntent，设置有限提交次数与有效期；复用既有 RunGrant、Team、RunIntent、独立审批和正式 Runner。任务只获准提交集合中的冻结清单，不获准准备新清单、修改源码或批准其他行为。旧主协调会话 Grant 和 owner 逐次批准入口保持原语义。

1. **固定授权到任务。** Grant 草案绑定确切项目、Team 计划、Task、角色、模型和 RunIntent 的 manifest/source/contract/原批准身份；Grant 与 Team 分别批准后才派发任务。准备和激活不启动 Pi、Docker 或正式 Run；任务上下文和尝试记录获得同一 Grant 引用。
2. **受限成功路径。** 当前有效的 `analyst` Task 尝试仅能调用 `run_submit` 提交集合内一项冻结 RunIntent；同一提交回执重放仍是同一 Run，永久计次一次。实际运行结果与原清单、Task 和 Grant 可回查；旧主协调授权继续可用。
3. **越界与失败。** 集合外清单、新 `run_prepare`、其他任务/会话/角色或旧尝试借用，模型/计划/身份变化、额度耗尽，均在新增 Run 前拒绝；失败、取消及 unknown 不退永久提交次数。Team 批准或 Task 租约失效只阻止新提交；RunGrant 到期、撤销或原批准失效仍阻止尚未启动的 Run，已合法启动或完成的历史保留。
4. **重开与历史。** 关闭重开后 Task、尝试、Grant、永久计次、同一 Run 回执与原产物按 ID 可读；原有记录、审批和文件字节不改写、不重跑已完成 Run。开发只跑相关检查；集成后一次全量回归、干净构建和独立权限复核。真实 Pi/Docker 只对本批关键后端路径各做一次，若环境缺失则标记跳过，不用模拟冒充实测；前端不验。

本批只补一项 Task 级固定 RunGrant，不扩展参数范围语言、其他 Task 角色或新的运行后端。
