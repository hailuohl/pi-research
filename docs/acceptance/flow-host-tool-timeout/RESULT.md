# 宿主工具 RPC 超时契约（2026-10-22）

范围：仅修复 host_execute 的 30 秒通信等待短于最长 60 秒执行，以及停止时等待未完成 RPC 的问题。

验收条件：

1. host_execute 在 45 秒和 74 秒返回时，原工具调用取得结果；只有一个请求和一份工具结果。
2. 其他工具仍保持 30 秒通信等待。
3. host_execute 真正超过 80 秒时，错误保留 tool、toolCallId、requestId，明确结果未确认及不要自动重试；迟到响应不替换原结果。
4. 宿主拒绝与 Worker 停止正确结束等待项；原有权限、命令去重、并发和未知状态阻断不变。
