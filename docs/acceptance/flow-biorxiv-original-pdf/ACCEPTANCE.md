# bioRxiv 指定版本原始 PDF：本批验收条件

1. 所有者显式请求 `10.1101/322859` 的 bioRxiv `v2` 原始 PDF；固定官方版本地址只计一次 HTTP，响应须是实际 PDF 字节，发布不可变 `DocumentVersion`、原件摘要和请求版本，版本保证明确为“地址请求、未做内容级核验”。本批不自动解析或入语料。
2. 来源关闭、缺少版本、来源不符、HTTP 失败或返回非 PDF 时，不发布可用 PDF；仅已发生的 HTTP 请求计量，不自动重试，不把摘要或 HTML 冒充原文。
3. 关闭来源并重开后，新 PDF 若成功仍能按摘要回查；旧 PMC 全文、检索、报告与失败历史保持原身份。跨项目读取拒绝。
4. 浏览器只回看本批固定 PDF、版本和限制说明；不触发 Pi、Docker 或 PDF 解析。来源站点若当前环境不可达，保留一次失败证据并按用户要求跳过该实网验收。
