# 本批验收：限制性 umask 下的 SSH 嵌套源码 Run

范围：修复已交付 SSH→远端 Docker 监管协议中嵌套源码目录受远端 `umask 077` 影响而不可由容器 UID 65534 遍历的问题。复用固定 SSH 目标、RunIntent、批准、唯一 handle、回环 Docker 和既有恢复协议；不接入 Slurm 或完整远程工作台，也不改前端。

1. **真实成功路径。** 在远端进程 `umask 077` 下，已批准的固定 Run 上传多级及隐藏路径源码；容器非特权用户读取原字节并生成声明产物，目录可遍历，文件仍为只读 `0444/0555`，私有 job/控制文件保持 `0700/0600`。回环 SSH→Docker 只启动一个对应 handle。
2. **越界与失败。** `..`/链接路径、来源摘要或批准身份变化仍在执行前拒绝；修复不能递归放宽 job 根、凭据或输出权限。旧无批准、容量、取消和未知回执保护不削弱。
3. **恢复与历史。** 关闭并重开控制器后按原 handle 回查该 Run 的日志、指标、声明产物和完整终态，不重复发 `start`；旧 SSH Run、记录和原生历史保持原摘要。协议更新后新目标须重新 probe；旧终态 handle 按原冻结身份回查，活动中的旧 handle 不跨协议升级。
4. **验证与交付。** 修复回归先在旧协议下暴露 `umask 077` 错误，再通过；开发只跑相关检查，集成后一次全量回归、干净构建与独立权限/恢复复核。真实回环 Docker 只验本批关键路径；没有外部授权主机，Slurm/live 远端仍明确未验。
