# 输入框模型与思考档位接线 · 2026-10-09

将已接受的紧凑浅色模型弹层接入聊天输入框。仅涉及当前会话模型选择、设置元数据读取与保存确认；其他前端布局沿用现状。

## 验收

1. 模型唯一来源为设置页同一模型目录，包含已有“本地配置”条目；排除停用、删除、缺凭据的条目，禁止前端从 bootstrap、历史或 SDK 全量目录另行合成。
2. 思考档位直接使用配置的 `id`、`label`、顺序和 `defaultLevel`。选择新模型使用其配置默认档位；重选当前模型保留其有效档位。0/1 档不可产生虚构选择，多档全宽等距排列。
3. 通过既有会话版本检查接口保存真实档位 ID，以匹配回执同步当前会话。失败恢复确认值；页面随后刷新失败也保留已确认模型及消息历史。
4. 保留任务、团队、执行、排队、归档、固定授权和过期事件限制。
5. 原生 popover/range；点击目标即时更新、CSS 120ms 移动；超过 3px 后连续跟随拖动，释放吸附合法档位；模型列表替换面板 140ms，12 个装饰粒子，支持减少动态效果。

## 实际验证

命令、测试统计、构建清单哈希与独立复核结果见本目录 `evidence.json`。原始日志及界面截图留在 `.validation/composer-configured-20261009/`，不复制原始会话或凭据到交付目录。

完整回归 1476 项：1452 通过、24 环境跳过、0 失败；最终构建后定向检查 48/48 通过。干净安装、构建与类型检查通过，635 个构建文件一致。独立复核结论可交付。

隔离真实 HTTP 服务与浏览器验证了 6/3/2/1 档模型：滑轨宽度均为 286.666687px，轨道高 31px，手柄宽 36px；设置名称、默认档位、键盘保存、切换与刷新后恢复一致，浏览器无错误。原有 5 个在途文件的 SHA256 与批前相同，未纳入本批提交。

## 限制与配置提示

已有“本地配置”模型继续可选，标签与默认档位以设置页返回的同一元数据为准。本批没有迁移配置、猜测档位或修改原有凭据。没有可用目录时提示在设置中保存模型；设置读取失败时禁止通过 bootstrap 旧列表回退。

未调用外部付费模型；已有运行集成测试使用本地供应商夹具及固定 Pi Worker。未在浏览器中独立驱动连续指针拖动，相关方法回归覆盖拖动阈值、连续位置、吸附与取消，实际 CSS 尺寸和 120ms 过渡已浏览器核对。

实施与独立复核分别使用独立的 GPT-6.1 Sol / high 会话；请求参数被接口接受，运行时未回显。主会话模型及思考强度未调整。
