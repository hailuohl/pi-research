## 实际数值示例

通过 `node dist/apps/cli/index.js demo-campaign --data <独立测试目录> --json` 执行：一阶基线，Refill二阶与三阶候选，根据实际mse保留一个结果，Promote到下一轮并执行岭参数变体，再Stop。四个Run都为succeeded / complete，源码快照、原始指标、证据和报告均实际产生。

这个命令是用户显式授权的固定随包数值测试。决定由确定性脚本提出，不是Pi生成，不调用模型、不执行DFT、不复现SCI论文，也不证明科研质量。Repair另有服务测试覆盖，本次四次成功数值计算没有假造修复场景。

`campaign-demo/run-summary.json` 是实际记录的静态导出；`metrics.csv`和报告来自同一批Run，报告字节摘要一并保存。运行数据库、凭据和本地访问令牌不随包发布。对象ID指向本次QA数据，新用户应执行自己的示例生成新对象。
