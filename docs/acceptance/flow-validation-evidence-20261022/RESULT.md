## 五项验收

1. 原命令、固定摘要、退出码、完整性、实际产物可追溯，缺失统计不编造：通过。
2. 手动读取单个原对象，历史执行、本次核验和科学判断独立：通过。
3. 来源变化 stale、损坏 fail、读取不确定 unknown，跨项目/会话/摘要越界拒绝：通过。
4. 后台刷新失败、重试等待、最终刷新失败及切换期间迟到响应不恢复旧通过：通过。
5. 真实关闭/重开恢复同一个 Run，未自动核验或重执行：通过。最终副本重开前后读取次数均为 5，Run/intent 各 1。
