# 验收手册：AIC「AI+开源」五日参赛MVP

本手册只定义未来实施的验收，不是已执行测试报告。当前产品实施尚未开始。任务状态以 STATE.json 为唯一权威。每个结果必须绑定真实代码快照、实际命令/操作和证据。赛题及截止日期在正式提交前再次核实。

## 官方导向

主方向建议为AI开发工具与开源协作，补充叙事为开源项目改进与生态贡献。按官方要求准备作品名称<=20字、简介<=300字、技术报告PDF建议<=15页且<=10MB、3–5分钟MP4且<=300MB、开源及第三方资源使用清单、有效成果链接与运行说明。参赛材料不得出现学校名称、学校Logo或指导教师信息。具体字段和规则以最新官方页面/附件为准。

## V-GATE：每批质量门槛

1. **基线**：记录HEAD、分支、dirty摘要、选定文件SHA、运行中进程和本批文件所有权。保留旧改动；纯HEAD副本可能漏掉已有能力。
2. **真实闭环**：至少一条用户流程从真实输入走到真实操作/结果，再到验证与保存交接。API 200、模型自述、静态页面或mock不能替代。
3. **定向测试**：先写能暴露目标差距的测试，验证成功与拒绝/失败场景。测试未运行记not_run，跳过记skip，环境不具备记blocked，不得改成pass。
4. **集成复核**：核心路径集成后运行当前快照适用的测试、类型检查/构建，并由独立会话只读复核实际diff、权限、失败状态与证据。无需每个小步骤机械跑全量回归。
5. **提交安全**：仅暂存本批明确文件；不全量暂存、不覆盖其他dirty内容、不擅自公开私密仓库。提交与远端同步单独记录。
6. **证据一致**：视频、报告、源码版本、测试结果相互一致。任何效果数值、性能、用户反馈都必须来自真实数据。

## S0：基线与赛题范围

- S0.1 核实当前HEAD、分支、dirty状态、在途进程和远端。
- S0.2 核实最新赛题、赛程、报名状态、团队授权和提交字段。
- S0.3 明确已有能力、本次新增改动和可展示差异。
- S0.4 选择一个能在五日内实现且可测试的核心问题，核对第三方许可证、模型条款、数据权属和公开范围。

证据：真实git状态、选定文件摘要、官方要求检查清单、范围决定。不得将原长期设计视作本次新功能。

## S1：端到端核心闭环

- S1.1 用户给出目标后能看到可执行计划，包括目标、操作/文件范围、验收、验证命令和回退。
- S1.2 用户确认后只执行授权范围内的真实操作，并能回查真实Task/Attempt或操作回执。
- S1.3 核心改进有可解释的前后差异；实际测试/构建显示pass/fail/skip/not_run及原因。
- S1.4 至少一条端到端路径可重复演示，另有一个失败/拒绝场景证明边界。

证据：代码diff、实际操作记录、测试日志、输出摘要与重开后的状态。

## S2：恢复、反例与质量

- S2.1 结束会话后，新会话能恢复同一任务、当前版本、已完成/未完成事项和下一步。
- S2.2 覆盖至少一种失败/中断/超时；超时不自动等于底层失败。
- S2.3 验证重试/重复请求不会造成重复副作用。
- S2.4 当前快照相关测试、类型检查/构建通过，并完成独立只读复核；缺少环境的路径如实标记。

证据：前后状态、原操作ID/TaskID、重复副作用计数、真实命令退出码、复核记录。

## S3：报告、视频和开放成果

- S3.1 作品名称和简介符合官方字数限制。
- S3.2 技术报告覆盖问题、方案、AI与开源资源、自主开发、实现、验证、创新、开放价值与合规。
- S3.3 资源清单覆盖所有实际使用的代码、库、模型、数据、素材及许可证/授权义务。
- S3.4 3–5分钟演示脚本和视频展示真实问题、输入、操作、核心结果、失败边界与复用价值。
- S3.5 架构图、真实测试摘要、版本/代码差异、运行说明和有效成果链接齐备；材料匿名。

证据：报告源稿/PDF、实际视频文件、资源清单、链接访问结果及文件SHA-256。

## S4：冻结与提交

- S4.1 在目标环境从头运行安装、启动、核心演示和关键测试，记录准确版本与命令。
- S4.2 报告PDF建议<=15页且<=10MB；视频3–5分钟且<=300MB，实际检查文件大小和播放。
- S4.3 报告、视频、仓库commit、开源清单对应同一版本；没有未披露的关键差异。
- S4.4 最终复核匿名、权属、许可证、秘密/个人数据和成果链接访问。
- S4.5 形成提交清单并核对真实平台回执。没有回执不得称已提交。

## 禁止伪通过

- 旧测试通过不能证明新功能通过。
- 设计/计划文档写好不代表功能实现。
- 模型说“已完成”不代表真实命令成功。
- 点击下载不代表文件可打开或内容完整。
- Git push成功不代表竞赛平台提交成功。
- 私密仓库存在不等于第三方资源可公开分发。
- 未完成的长期功能不能写成参赛作品已实现。
