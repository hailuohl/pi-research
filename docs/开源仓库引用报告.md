## 3. 引用合规要点（摘要）

1. 每项源码级适配保留上游许可/声明文件与逐文件 blob/sha256 来源清单（`third_party/*/`、`third-party/paperqa/`），适配范围明确窄于上游，不宣称上游背书。
2. 随 dist 分发的第三方许可全文只有 React/ReactDOM MIT（`dist/web/LICENSE.react.txt`）；其余 npm/镜像组件不进发行物。
3. 下载文献保留自身许可，获取记录不授予再分发权利；成果包导出保留许可记录，许可未知不改写为已获授权。
4. 详细分发声明见 [THIRD_PARTY_NOTICES](../THIRD_PARTY_NOTICES.md)；本地 main 线的工程盘点见 [开源及第三方资源使用清单](THIRD-PARTY-RESOURCES.zh-CN.md) 与 [技术报告](TECHNICAL-REPORT.zh-CN.md)。
