# 尺度律

回答指标如何随模型、数据或计算尺度变化，以及未运行尺度上的预测。log-log散点加拟合线只是形式；四个点总能看起来像直线，必须验证拟合。

## 拟合本领域的模型

有不可约下限的loss/error应拟合 `L(N)=E+A·N^(-α)`，不固定E=0。E为数据熵/Bayes误差等下限；强迫为0会弯曲拟合并压平α。误差拟合在L上，不在 `log(L-E)` 上，后者会让近下限点占支配地位。若E逼近0或min(L)，这些运行没有约束下限，说明这一点，不能把边界当测量。给α区间，可对运行bootstrap；方程和区间放图中。

## 纳入拟合的条件

- 仅一个机制区间：欠训练、warmup受限、另一瓶颈的点可画，但不能一起拟合，要说排除了哪些。
- 至少4点，最好跨一个数量级。少于4点或只跨3倍叫趋势线，不叫尺度律。
- 运行可比：相同数据、tokenizer和评估；不能暗中混不同评估集。
- 数据范围内实线，外推虚线并遮阴。未测量区域不可画成实线测量。

## 常见错误

| 错误 | 处理 |
|---|---|
| 10^8/10^9刻度难读 | 网格可用幂，刻度用 `si_ticks` 显示100M/1B |
| 隐藏残差 | 添加残差条，曲率表示模型形式有问题 |
| 不标拟合点 | 纳入点实心，排除点空心，并在图注解释 |
| log轴无量/单位 | 清楚标参数、计算等实际量 |
| α只在图注 | 图内显示方程、α区间与运行数 |
| 多模型家族仅靠颜色 | 每个家族一种标记，规律也可能不同 |

## 完整模板

保存 `figs/scaling.py`，输入 `figs/scaling.csv`（`family,n_params,loss,fit`），fit=1的点用于拟合。`PREDICT_TO` 是明确的外推终点，不能当测量。无SciPy依赖：扫描α，每个固定α线性最小二乘解E/A；bootstrap剔除退化重采样，成功样本不足就停止。代码亦在 `examples/scaling.py`，所有数据必须换成真实来源。

完整可复制模板：[examples/scaling.py](../examples/scaling.py).
读取工具 research_skill_read 的 input 使用本技能ID，resource为 examples/scaling.py。

## 验收

- E与其是否受约束已报告；α带区间并写拟合运行数。
- 至少4个可比运行和有依据的拟合区间；排除点明确。
- 虚线/阴影标外推，残差无系统性曲率；拟合形态不成立则不声称尺度律。
- 刻度易读、log轴量名清楚、审查通过并看实际PDF。
