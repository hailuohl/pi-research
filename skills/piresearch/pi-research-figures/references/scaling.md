# 尺度关系与非零地板拟合

参数量、训练量或成本的定义应在轴标签或图注中交代。示例横纵轴均为正量，使用双对数显示；拟合仍在原始 loss 尺度最小化平方误差，不是对 log(loss) 作直线回归。模型为 L=E+A*N^(-alpha)，E>=0 是渐近地板，A>0、alpha>0 描述随规模衰减的部分。省掉 E 会改变模型与科学含义。

`scaling.py` 保留 DATA、PREDICT_TO、load、fit_power_law 和 bootstrap_alpha。load(path) 按 CSV 原行序返回 n_params、loss、fitted 布尔和 family 字符串四个数组；fit 必须为 0/1，参数量严格为正且所有观测有限。所有 family 中 fit=1 的行共同拟合一个模型，fit=0 行仅作 heldout 展示，不参与拟合或 bootstrap。对数显示另要求 loss>0。

fit_power_law 默认在 np.linspace(.02,1.5,800) 的 alpha 网格上进行剖面搜索。对固定 alpha，以平移缩放后的 N^(-alpha) 为基函数，解析求无约束截距与振幅；若所得 E<0 或 A<=0 则跳过该 alpha，不把负截距投影为 E=0。只保留 E>=0、A>0 的有限候选，并在原 loss 尺度选择最小平方误差，返回 (E,A,alpha)。无合法候选时明确失败。函数允许两个不同 N 的两行输入，但这种计算不能识别三个自由参数或支撑完整模板的 bootstrap 区间；完整模板仍要求足够原行。网格精度及范围是明确的估计限制，不等于连续参数的解析最优或理论证明。

bootstrap_alpha(n,loss,draws=200,seed=0) 对配对的 (N,loss) 原行有放回重采样。少于三个不同原行的重采样或没有合法拟合的抽样跳过；成功数少于 draws//4（或无成功样本）明确失败。返回成功 alpha 的 2.5/97.5 分位。行 bootstrap 要求原行可作为重采样单位；相关测量、重复配置或层次抽样需要先验证设计，不能将此区间当成通用置信保证。
