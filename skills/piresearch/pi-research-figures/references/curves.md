# 学习与训练曲线

回答指标随训练怎样变化，以及方法差距是否超过种子噪声。错误横轴和单一种子会在成图后悄悄误导。

## 先确定横轴

| 比较情形 | 公平横轴 |
|---|---|
| 同配置不同种子/代码改动 | 优化器步数 |
| batch或序列长度不同 | 实际tokens或样本数 |
| 模型大小不同 | FLOPs；若用tokens须逐线标模型大小 |
| 速度/效率主张 | 墙钟时间，并说明硬件 |

步数减半但单步耗时翻倍并非更快。模板CSV字段 `step` 表示优化器步数，所以轴也标步数；若用tokens，必须从真实计数导出并同时改字段语义和轴名，不能仅改标签。

## 聚合所有种子，不挑一条

通常至少3个种子，效应小可5个；均值作线，95%区间以同色低alpha阴影，用 `band()`，图注写n。±1SD是种子离散程度，不是均值的区间。若种子定性分歧（如一条发散），用细线展示个体，不能用宽阴影藏掉。日志网格不齐先在共同到达范围插值；`np.interp` 范围外夹值会伪造提前停止运行的平尾，不能这样外推再聚合。

## 平滑也是证据变换

训练损失可平滑，但图注明确算法/参数（如EMA α=0.1），底层显示淡色原线。稀疏评估指标不能平滑，它会制造未测量的点。

## 常见错误

| 错误 | 处理 |
|---|---|
| 截短y轴夸大差距 | 保留相关范围；放大窗口在图注声明 |
| 未解释log轴 | 轴名声明；跨数量级或比值主张才用log-y，4.7→1.6的有界loss通常线性更清楚 |
| 图例盖住关键区域 | 右端 `label_ends` 直接标线 |
| 太多曲线 | 保留支撑主张的约4条，其余附录表 |
| 基线用强调色 | 使用灰色 `BASELINE` |
| 曲线截止范围不同 | 图注说明发散、预算耗尽等原因 |

## 验收

- 横轴公平且有单位；跨种子均值和95%区间，n写图注。
- 每个种子共同覆盖范围内聚合；个体分歧保留。
- 平滑参数已声明且原线可见；不平滑稀疏评估。
- 灰基线、约4条强调曲线、诚实y范围；提前停止有解释。
- 检查 `save()` 审查并查看打印尺寸PDF。
