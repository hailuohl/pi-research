# 权衡与Pareto前沿

回答奖励/KL、准确率/延迟、质量/参数或成本的取舍。若方法有旋钮，单个操作点是设置选择而不只是方法成绩；换β排名会翻转，前沿才是主张。

## 前沿为主张，所有运行为证据

所有运行淡标记，`pareto_front()` 的非支配点按前沿连接，比较整个范围上谁更接近左上好角落。不能隐藏被支配点，散布会显示不稳定或无效设置。前沿连线是视觉指南，不表示中间未测量/离散设置可达到，必要时在图注说明。

明确两个轴的好方向，如“KL divergence (lower is better)”。数据留下空好角落时才放better↖箭头；若主张恰是达到好角落，这个位置通常有数据，检查实图。拥挤可用极淡背景分区，不让文字抢空间。FLOPs、延迟、参数、tokens等成本跨多个数量级时用log轴，避免廉价端挤压。

## 扫描预算也是结果

12设置比3设置更易有优秀前沿；图例/图注写每方法设置数且预算可比。不能不解释 unequal budget。种子不得先折成一个平均值隐藏散布；保留同设置的种子范围。

## 编码

- 方法用形状和色相冗余编码，保证灰阶/色盲可读。
- 只有当旋钮影响本身为故事时按设置着色。超过约6设置图例难读，直接标关键2–3设置，其余不逐项图例。
- 有序旋钮可用明暗，形状=方法；两个变量两通道，不再叠加第三个色条。

## 常见错误

| 错误 | 处理 |
|---|---|
| 按运行序号连线 | 仅连接非支配前沿 |
| 只画前沿 | 被支配运行淡画 |
| 不比扫描额度 | 报告n设置并匹配预算 |
| 不说明好方向 | 轴名或空好角箭头 |
| 多数量级成本线性 | log成本轴 |
| 每超参值一个图例 | 直接标关键设置 |
| 种子先均值再只画前沿 | 前沿和设置内种子散布同时展示 |

## 验收

- 全部运行可见；连线只穿非支配点且说明是指南。
- 扫描设置数与预算可比；种子散布未隐藏。
- 两轴好方向明确；需要时成本log。
- 形状+色相可区分，无多余第三通道；审查并看实图。
