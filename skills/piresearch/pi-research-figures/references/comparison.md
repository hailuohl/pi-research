# 方法比较与消融

分组柱图用于比较少量基准上的离散方法。`benchmarks.py` 读取 `benchmark,method,score`，按 METHODS=[(name,group)] 与 BENCHMARKS 声明顺序分组，base 灰色、prior 蓝色系、ours 红色系，在每根柱末端显示原分数；类别未知或同一方法/基准重复时拒绝，缺失组合留空。它只有每格一个分数，没有足够信息生成误差棒。横轴保留 Accuracy (%)，真实数据必须确为百分比准确率；指标方向和可比性由研究定义，不把不同基准的数值直接相加作为新指标。

消融图用于回答相对明确参考配置的变化。`ablation.py` 读取 `variant,seed,value`，REFERENCE 默认 baseline、HIGHLIGHT 默认 ours，可按已确定设计修改；数据必须包含配置的参考臂，各臂每个 seed 只能出现一次。打印每臂实际独立重复数；比较臂按 treatment−reference 差值升序显示点和双侧 95% Welch 区间，HIGHLIGHT 红色强调并为每项标出带正负号差值，零线表示参考值，不把 baseline 与自身误当成两独立组比较。

`diff_ci` 将两组输入分别整体展平后返回标量，不为多维输入隐含新增逐列比较。调用者必须确保展平后的元素是独立重复，不能把相关时间点当成独立单位。Welch 标准误为 sqrt(s₁²/n₁+s₂²/n₂)，自由度使用 Satterthwaite 公式。临界值表按向下取整后的可用自由度保守查找，超过 120 仍用 1.980。任一臂不足两次独立运行时警告并返回点值；两臂均常量时区间退化。相同 seed 名称不自动产生配对设计；若实验是配对的，应先确定对应统计方法，不能套用独立组区间。

不以区间是否跨零替代完整显著性、多重比较和效应意义分析。列明独立单位、基准定义与缺失数据。长方法名可使用横向柱并保留至少 5pt 字体，按最终打印宽度检查所有数值及图例。自动重叠审查仍需结合实际 PDF/SVG 核实。
