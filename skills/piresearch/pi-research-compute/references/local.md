# 本地示例与 Docker 执行边界

依据已读取的上游 orx-compute 总览改写；不是宣称已获取或移植完整后端实现。

trusted-example 只运行随包固定数值程序，源码哈希不同即拒绝，不是任意宿主代码沙箱。Docker 需要固定镜像摘要、固定源码/数据与声明产物，容器禁网、只读根、非特权用户及有限 CPU/内存、PID、时间和输出；不传入宿主环境或密钥，不挂载 Docker socket。走 run_prepare → 用户批准 → run_submit；日志、取消与产物由现有 Runner 监管。改变源码或契约必须重新准备并批准，关闭会话不删除或取消 Run。

本机 Linux CPU 正式 Run、开发测试、取消及同容器恢复已有实测；不证明 GPU 或其他主机。CPU/内存限制不是 GPU 调度，当前目标可用性另看探测和队列。unknown 时保留原作业与资源预留，按原容器身份对账，不盲目重提。

先查 connector_status，再核对目标配置和运行条件。缺条件时说明具体限制，不把连接失败称为后端未实现，不回退调用 ORX、外部 CLI 或任意 Shell 绕过审批。
