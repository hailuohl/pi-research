# 科学一致性与限定修订

论文写作、科学审查或按意见修订前，用 `research_skill_read` 读取当前会话固定的 paper 主技能和本 resource。本文约束如何使用已获准输入，不授予读取其他来源、执行命令、修改审核状态或扩大任务范围的权限。正文与独立来源记录继续分层；真实引用、科学符号、单位、负结果和限制应保留。

## 方法深度按问题补齐

本resource继续负责下文逐条核对和限定修订，不以方法资源替代真实来源。涉及分析选择/依赖结构、效应区间、诊断或阴性结果时，用 `research_skill_read({input:{skillId:"pi-research-evidence",resource:"references/statistical-analysis.md"}})`；涉及测量模型、协方差、Type A/B、覆盖因子或有效数字时读 `pi-research-evidence` 的 `references/uncertainty-and-units.md`；偏倚、识别性与结论外推时读 `pi-research-evidence` 的 `references/scientific-critical-thinking.md`，均以该skillId和精确resource调用research_skill_read。paper所有角色均可读取evidence方法；需要设计或样本量补证交主协调者，writer不被路由到不可读create/experiment-tree。

统计置信区间、测量覆盖区间和样本SD各自核对来源与含义；不能将本参考中的一般规则或新增方法文字写成检查已执行。独立reviewer仍按固定输入与现有Task合同处理，缺原始数值或计算证据保留验证缺口。

## 从原始记录到每条主张

先实际读取获准的固定文稿、数据和证据内容；目录、摘要、引用 ID、构建通过和上轮助手总结不能代替原始数值。分页产物继续读取主张所需部分，未读范围明确记录。为关键主张核对条件/组别、指标定义与方向、原始值及精度、比较顺序、单位、检验、校正族和来源位置，必要时在独立来源记录列出对应关系，不把内部 ID 填进正文。

- 先确定差值是 A−B 还是 B−A，以及指标是最小化还是最大化，再判断“更好/更坏”。更换参照组时同步重算或反转差值与效应方向；不能颠倒比较文字后沿用原 effect sign。区间、效应量和结论必须对应同一比较。
- 结论仅覆盖实际测试的政策、条件、样本、时间窗和对照。某一条件成立不能改写为 all/始终/所有方案；检查逐条件结果，区分一致方向、混合结果与未测试条件。平均表现也不能证明每个条件均成立。
- 有未舍入原值时按原值判定 p 值阈值；只有舍入记录时仅用其支持的界限，注明精度，不补造精确值或为此擅自重算。显示为 0.05 不足以断定严格小于 0.05；来源存储或显示的 p=0 可保留并注明精度，不能据此声称真实 p 精确为零。记录支持的界限足以判定阈值时可以作相应有限判断，否则注明不能判定。分别报告原始 p、校正后 p、阈值及实际检验名称，不能从结果猜成另一种检验。
- 核对主指标、次指标及各自的 primary/secondary 多重比较校正族、族内比较数和校正方法。不能混用校正族或把原始显著当作校正后显著。均值的置信区间描述均值及其估计方法；秩检验描述其实际检验对象，二者不必给出相同结论，不能把秩检验的 p 值称为均值差检验的证据。
- 核对量纲与定义，例如单价 r（USD/kWh）和总额 R=rE（USD）分别报告，不能把单价或比率解释成总量。效率注明单程或往返及其计算方式，不能默认相同或无依据换算。归一化、百分比、百分点和绝对量也分别核对。
- 明确实际优化目标、约束、搜索范围和算法：优化某目标不能声称直接优化了事后评价指标；可行解、局部解或有限搜索最好结果不能称为已证明全局最优。描述相关、条件分组差异、事后评价和因果机制分开；没有相应设计或分析，不把观察到的关联或指标改善解释成机制证明。

逐条对照摘要、结果正文、公式、表/图及标题、讨论和结论，防止同一主张在一处改正而另一处继续错误。来源缺少关键数值、条件或检验记录时，保留具体缺口与待核对状态，不能凭常识补数、补检验或宣称科学核对通过。

## 独立 reviewer 的实际核查

先 `task_context_read`。developmentReview 仍按开发审查入口处理；只有 publicationReview 或明确的论文/科学文稿任务使用本流程。

固定论文审查先 `evidence_read` 实际读取全部 requiredEvidenceIds/inputEvidenceIds；从固定目标证据的 files 和 artifactIds 找到获准稿件，用 `artifact_read` 阅读实际 TeX/BIB、数据、必要构建日志和指定来源。ID 齐全不证明读过内容，TeX 可编译不证明科学正确。核对版本、sourceDigest 和上述主张依据，不能用可变工作区或另一版本替代固定输入。没有获准图像时仅审实际可读内容，不能声称看过 PDF 页面。审查不授予 PDF/PMC 原文访问；引用外部原文未独立核验就明确写未核验。

审查意见写入既有 `task_result_submit.summary`，给出可定位的章节/句子/表项或行号、原文主张、实际来源位置与值、比较/统计解释错误及其影响。可验证的关键错误给出 reject；来源冲突或尚不能确定的关键主张给出 disputed，并说明需要什么证据；必需输入无法读取则如实 blocked。只在本次有限范围的关键核对完成且无阻断时 accept，并保留未覆盖范围，不把它称作已证明全部科学结论。verdict、evidenceIds、claims 等仍遵循现有任务合同；固定论文审查 claims 为空，不创建自己的文件产物或改写被审稿件。

## 限定修订：保存新稿并证明改动范围

1. 先实际回读获准原稿，固定 baseline 的 artifact ID/digest；有固定修订时同时记 revisionId/sourceDigest、文件路径。工作区修改先读当前 digest。保留原稿产物与旧固定版本，不覆盖或清理历史。
2. 写入前列出获准改动位置及精确 old/new 替换文本，包括删除项、对应上下文及匹配次数，保存在已有独立文本产物/来源记录中，不新增平台字段。每个 old 必须与 baseline 实际匹配；重复文本须明确哪一处。若同一科学错误还出现在许可之外的摘要、表或结论，交主协调者统一决定是否扩充获准清单，不能擅自改掉其他部分。
3. 以 baseline 全文为基础仅实施清单内替换或删除。当前 `artifact_create`/`workspace_write` 写入全文，不是 patch 工具；不能只写出修正段落后称完整稿，也不能追加改正句而留下应删除的错误原句。保留所有非目标字节，包括段落顺序、句子、脚注、限制、表格、引用和换行，不用“语义相同”替代逐字要求。新产物保存新版本；固定稿由主协调者用真实 previousRevisionId 关联旧稿。
4. 保存后用 `artifact_read` 或 `workspace_read` 回读实际新内容，读取覆盖全部需比较的文本，核对每项新文本与删除项：指定位置已替换、旧错误句在应删除位置已消失、未新增重复主张。按 baseline 和获准清单构造期望全文，与实际保存字节做机械比较，并提供可核对的真实 diff，确认所有改动都在许可内、未触及区段完全保留。字数、digest 变化、模型自述或复述替换清单都不能证明这一点。
5. 仅使用当前获准且确实提供的比较能力，不发明 patch/diff 工具、不从本文推断 shell 权限。无法机械比较时，把真实 baseline、新稿和 old/new 清单交协调者复核，明确“新稿已保存、范围保持待验证”，不能声称严格通过。缺少 baseline 或关键来源时先报告缺口，不盲目重写；有限上下文无法读全时也不能承诺逐字保留。

交付分别报告科学核对、限定修订比较、编译、视觉检查与独立审查的实际状态。后续新稿重新走已有固定、构建与审查流程；旧结果和意见继续可回读，不能代表新字节已通过。
