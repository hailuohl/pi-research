# 数据分析

核对当前CSV行的含义、数值列、组别、单位及资料性质。合成/示例必须在来源data_label和稿件方法中说明；用户没给数据时不制造研究结果。原CSV保持，输出cleaned.csv与cleaning.json。

首版仅描述统计：逐组n、均值、中位数、最小/最大和样本标准差（ddof=1）；单样本SD未知而非零。缺失默认失败，用户认可排除规则才使用missing=exclude并报告排除行；非法数值、非有限值、坏CSV行、缺列或无有效样本失败。单位由用户确定，不自动推断或换算。

解释从实际result.json读取，核对组别、指标方向和样本数。描述差异、关联和因果分别说明。本版未做检验、置信区间或机制验证，不自动p值、不写显著或证明有效。正文数值用value标记引用实算结果，不手写成实测数字。
